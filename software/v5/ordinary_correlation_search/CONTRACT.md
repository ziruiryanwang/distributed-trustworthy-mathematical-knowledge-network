## Fixed semantic contract

The immutable profile uses these canonical fn/arg-only paths:

```text
0: [arg, fn, arg]
1: [fn, arg, fn, arg]
```

For a theorem preview, validate the complete type, strip all leading foralls,
and observe the two endpoints without entering binders. A required equality
exists only if both complete paths end at the very same stripped parameter.
Early parameter encounters, missing paths, and rigid endpoints impose none.

- Required equality: emit only the `equal` query-partition feature.
- No required equality: emit both `equal` and `separate` features.

For a query, validate existing raw formal-query bytes and strip exactly the
explicit nonnegative context-binder count. Emit `equal` iff both endpoints exist
and their full syntax agrees under the existing exact-type-key quotient;
otherwise emit `separate`. Two absent endpoints are not equal. The quotient
ignores display labels but preserves exact portable constants, universe instances,
bound indices and other structural fields. It performs no reduction. Use bounded
DAG computation, never tree expansion; refusing incomplete computation is safe,
silently treating it as unequal is not.

Reusing `formal_query._structural_key` for the two endpoint roots is permitted
after complete ordinary query validation. Two bounded passes are preferable to
introducing a second subtly different canonicalizer; count both passes. Internal
packet-root replacement must not mutate supplied/retained data. Hash collision
can add a false-positive equality, never mathematical authority.

The query feature tag is `conclusion-correlation`, with `profile_id` and `value`
fields; value is exactly `equal` or `separate`. A new domain and PROFILE bind the
meaning. `separate` includes missing endpoints and does not assert mathematical
inequality. Source feature emission describes possible query partitions, not a
theorem about the source parameters. Only kind-2 theorem records receive these
features. No goal-derived symbol or head conjunct is automatically added.

Conditional guarantee: if the goal is a capture-avoiding raw instance of the
source conclusion in a common explicit context, the generated feature belongs
to that source's complete feature set. This is not applicability, proof of
premises, exhaustive provider coverage, or mathematical acceptance. Supported
syntax/resource/profile conditions and honest complete indexing remain premises.
