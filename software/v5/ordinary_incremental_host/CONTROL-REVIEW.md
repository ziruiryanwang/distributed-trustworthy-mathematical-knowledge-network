## Scope and limitations

The injection wrapper calls the real store method and raises only after it
returns from its transaction. It deliberately precedes the helper's progress
append, so the unknown-commit reporting branch is exercised rather than mocked
as complete. Patches are exited before reopening and before the explicit second
append. There is no automatic test retry or reset after a failed group.

These are Python exceptions with orderly unwinding, **not process termination,
hot-journal recovery or power-loss tests**. They support the implementation's
committed-prefix structure; SQLite's interrupted-transaction and filesystem
premises remain separate. Single-process two-handle lock contention is not an
independent-host isolation test. Corpus size, discovery usefulness, mathematical
acceptance and full-v5 completion are outside this control suite.
