# Exact location: reconciled architectural choice

2026-10-28, root. Read all three final source notes. No location runtime or
implementation is selected by this decision.

The missing capability is locating an independently retained support export
whose custodian is absent from the reader's configured sources. Known suppliers
already work. Grouped referrals and arbitrary exact-key routing solve different
coverage problems; they are not interchangeable implementations of one promise.

For the eventual large-network capability, prefer the existing maintained DHT
behind replaceable read-only gateways. It admits independently operated holders
without requiring every upstream contributor to maintain a referral to them.
Readers need only Python and approved HTTP endpoints. Operators explicitly fund
their own finite publication, renewal, storage and gateway service. No global
consensus, permission to publish mathematics, or mandatory certificate is added.

Defer grouped dependency sidecars. They require metadata not retained today,
their stable descriptor anchors still require service, and they cannot find an
unannounced independent mirror. Building both now would duplicate the reader
integration without resolving that coverage gap. Grouping remains a possible
later optimization if measured publication/renewal multiplicity warrants it.

This is a direction, not an instruction to implement the entire DHT cut before
repairing the existing ordinary transport. The source findings expose concrete
integration work: create/reopen, consistent finite IPC capacity, pending intent
recovery, conservative lifetime translation, async gateway and aggregate reader
budgets. They must be selected as one useful operator workflow, not presented as
already supplied by an exact-key hash or a static map.

The startup charged-key invariant P subset-of S, |S| <= K removes the repeated
publication census under serialized ownership. It does not remove startup,
provider maintenance, or global advertised-holder/key costs. Selective publication
and bounded service explicitly permit incomplete coverage. Search for useful
mathematics, location of known support, sound admission and useful growth remain
different properties. The current 192 MiB controller limit is authenticated
runtime payload size, not RAM; this corrects the earlier decision note.
