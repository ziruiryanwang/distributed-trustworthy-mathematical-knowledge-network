builder remains an unexecuted candidate. No runtime, native build or state
operation has occurred during control authoring.

The suite pins the new builder, map and preserved helper. It checks only the
changed source-selection/controller boundary. It does not rerun mathematical,
network, certificate or predecessor path/ZIP campaigns.

2. Every selected lane/header transform produces its separately pinned output;

6. A deliberately wrong core import origin stops before any compile stage.
7. Missing final child CPU data charges the whole grant, preserves failure
   evidence and stops after the first stage, without a PROFILE or retry.

native markers, and explicitly labeled `SYNTHETIC-FIXTURE.json`. Only the runtime

database, existing owner or network service runs. Core imports are isolated and
removed between cases; module search paths and patched globals are restored.
