# Focused native-free grounded-cut controls

SOURCE ONLY: root has not selected execution. The test is not mathematical
acceptance, native verification, package qualification or a growth measurement.
Independent source review must precede a single finite root-selected run.

## Inputs and isolation

The test accepts `--source-root` pointing to the runner's selected source snapshot
and `--output` pointing to one fresh directory below the canonical project's
`experiments/`. It does not import live canonical product source. The snapshot
contains six selected ordinary codec/controller sources under `ordinary_lean/`
and seven grounded-cut sources under `grounded_cut/`; exact names appear in the
test's fixed loading list. Root must pin the complete snapshot and test before
launch. The report records every loaded source size/hash.

Run only in the selected Windows isolated/no-site/no-bytecode interpreter with
the canonical project as cwd. Secondary nonrenewing in-script guards are 60 wall
seconds and 30 process CPU seconds; the outer runner independently supplies the
actual finite process/memory/output envelope. No native process, network request,
installation open, existing protected catalog or source migration is performed.
All generated files are synthetic and remain inside the fresh output directory;
the test does not remove existing files or change Git.

## Actual boundaries versus doubles

| Boundary | Exercised implementation | Explicitly excluded |
|---|---|---|
| Persistent map | Real SQLite database and `cut_map` | A protected rooted mathematical catalog |
| Summary preparation | Real evidence codecs, projection, closure and budgets | Lean typing or authentic fixed basis |
| Extend/resolve flow | Complete actual controller functions | Native runtime, source anchor, catalog authority, custody are doubles |
| Runtime cleanup | Actual `CutRuntime.check_packet` around a synthetic supervisor response | Native child process or real installation |
| Loader refusals | Actual module-graph checks and preloaded/base guards | Successful installed support loading |

The synthetic theorem claims deliberately need not typecheck. The 581-entry
basis is a parser precondition double, not the real basis. The successful fake
worker returns visibly synthetic bytes; tests establish that orchestration uses
and orders its designated authority seam, not that a fake response is evidence.
No return from the suite may be called a grounded theorem or an accepted root.

## Focused cases

- Map: close/reopen persistence, old-root exact absence, identical insertion,
  conflicting binding, zero allowance, rolled-back prefix and selected corruption.
  Trace assertions require visited-node SELECTs to remain exact primary-key reads.
- Summary: omit old proof-only ancestry, require exact parent membership and
  symbol identity, reject changed summary hash, reject a demanded alias absent
  from the fetched group, and reject concrete semantics needing an omitted old
  theorem proof.
- Controller: derive the updated map from the named parent, persist exact intent
  before commit, resolve simulated reply loss without rechecking/recommitting,
  report exact absent-root disposition only after successful store access, and
  propagate pending-recovery refusal. Missing intent cannot trigger a retry.
- Controller failures: sibling-only import, changed frontier, post-worker global
  name collision, custody claiming mathematical authority, source withdrawal and
  uncertain child cleanup all prevent commit. Uncertain cleanup writes withdrawal.
- Runtime: a saved success-shaped report cannot override an actual same-call
  observation showing unclosed/live child state.
- Loader: reject mixed helper objects, a controller pointing at a different
  runtime module, preloaded cut modules and replacement base admission objects.

Successful controls only establish these finite implementation behaviors. They
do not qualify actual migration, genuine worker checking, support withdrawal in
an operating installation, SQLite crash recovery, source sandboxing, performance
or deployability. Source review of the complete graph remains independently
necessary; later native selection must test the real mathematical boundary.
