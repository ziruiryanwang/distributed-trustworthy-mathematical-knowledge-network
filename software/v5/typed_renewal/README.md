# Ordinary typed renewal

Source-only owner strategy for the fixed `context_transport` U to
`context_transport_then` V step. It composes the current candidate130 SDK; it
does not change a verifier, install a runtime or create a proof automatically.
Actual execution awaits a genuine resolved A*(H_U) receipt and root's separate
finite selection. Existing conditional fixtures are not that receipt.

## Owner entry

Select the unchanged130 SDK files from
`experiments/v5-local-checks/distribution-candidate-preflight-01-input.json`.
Supply these two owner files through the existing contained client boot:

| Boot role | Source |
|---|---|
| `owner/owner.py` (entry `owner.py`) | `typed_renewal/owner.py` |
| `owner/renewal_source.py` | `typed_renewal/source.py` |

There is no SDK installation expansion. `__init__.py` is only for source-side
package use. The helper is loaded through the existing pinned import guard.
The candidate installation still defaults to aggregate image `99b9f1cf...`
and its old aggregate executable. These defaults are not A* adoption. Root must
select fresh A-only `runtime_adoption.aggregate.executable` pins for the reviewed
image-parametric verification host and `aggregate.image = 9d5072a6...`, with
matching workspace/support/TrustDomain. Reusing130 SDK sources does not override
the distribution's defaults or reinterpret any old trust domain.

`run(context)` is async; `main(context)` returns0 only after successful work
and clean closure. Parameters have exactly these fields:


Every file pin is the existing `{path, bytes, sha256}` form. There is no source,
native witness, BASE opening or original I receipt parameter. `v_source()`
constructs the reviewed four-universe theorem with the exact relocated U name.
The fixed V module identity binds its full statement; the actual exported proof
must have18 matching lambda binders and exactly U's application as the first
equality argument of `Eq.trans`. A syntactic occurrence count is insufficient.

The operation verifies U through `admit_aggregate_member`, imports only its
theorem interface, authors V once and validates the actual emitted source/
packet. It then independently calls the current `admit_local` with
`expected_exact_journal`, and compares the returned live journal. No conditional
fixture-generated V witness substitutes for this actual authoring/checking.

Successful output is `typed-renewal-result.json`, `V.packet.json`, `V.journal`
and `V.lean` under the operation's output workspace. Source/worker evidence
and costs remain in the ordinary grant. `local_U_and_V_admitted=true` records
the actual successful local issuer calls. `mathematical_acceptance=false`
means this saved report itself is not transferable mathematical authority;
it does not negate those local facts or turn the saved V packet into a resolved
certificate. The client and workspace close, and only this explicit temporary
domain is withdrawn. A partial domain-creation failure remains state-unconfirmed,
not falsely reported as withdrawn; any cleanup uncertainty prevents completion.

## Separate preparation API

The pure helper inputs are:

```python
material = dict(schema="DMKN_TYPED_RENEWAL_MATERIAL_V1",
    receipt=receipt_bytes, header=header_bytes, journal=journal_bytes,
    member_index=index, siblings=list_of_32_byte_values, opening=group0_opening)
validate_material(material)  # Structure/membership only, NOT receipt verification.
validate_renewal_packet(raw_V, exact_J_V, material, envelope=envelope)
prepare_renewal(already_selected_producer, raw_V, exact_J_V, material,
                envelope=envelope)
```

`prepare_renewal` imports no specialized producer. The caller supplies its
already selected typed producer; the ordinary consumer never calls this method.
It checks the exact tag1 receipt, sole U frontier and V delta, then delegates to
the unchanged producer `prepare`. The expected seal census is1/1/1/2/1 for
claims/frontiers/deltas/members/edges, rank2 and height2. Producer preparation
can check its source/runtime pins but dispatches no snapshot or proof here.

The prepared seal is still untrusted. Later snapshot, graph pricing, funded
production and independent A*(H_V) acceptance are separate root decisions.
This code is a fixed capability adapter, not a universal agent strategy or a
claim of profitable certification, useful growth or final-v5 completion.
