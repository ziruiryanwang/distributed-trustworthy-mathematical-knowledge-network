## What a pass would mean

A pass supports one local dedicated nonchecking host generation that serves
existing exact evidence through existing search/preview/inspect without owner
grounding. It does not establish full dependency completeness, native acceptance,
new mathematical growth, broad recall, internet deployment, independent-host
failure tolerance, continuous service or final v5 completion. Prior accepted
mathematics remains separate evidence; this host must report no mathematical
acceptance even when the inputs were previously checked elsewhere.
