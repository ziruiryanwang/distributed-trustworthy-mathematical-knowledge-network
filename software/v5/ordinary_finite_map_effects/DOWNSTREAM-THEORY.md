# A downstream theory of nonemptiness refinement

Source-only proposal, 2026-10-26. `kernel_package_audit`.
No Lean source, execution or new mathematical acceptance is produced here.
The earlier finite-map theory's proof review is reused, not repeated. Its actual
contribution must succeed before a downstream agent can acquire its checked
interfaces. This is a proposed new-to-network extension, with no claim of
worldwide mathematical novelty.

## New concept: a property-specific semantic refinement

Retain the exact existing `Plan`, `Exec`, `mustWrite`, and assumptions
`[BEq K] [Hashable K] [EquivBEq K] [LawfulHashable K]`. Define

`N(p,m) := forall n, Exec p m n -> n.isEmpty = false`.

Define `p <=N q` to mean `forall m, N(p,m) -> N(q,m)`: replacing `p` with `q`
preserves any guarantee of a nonempty result. This orientation permits `q`
to establish a guarantee that `p` lacks. It is a relation on mathematical
program semantics, not syntactic equality or inclusion of all execution traces.

A one-hole context is generated by a hole, sequencing a context with a fixed
plan on either side, or choosing between a context and a fixed plan on either
side. `C[p]` fills the hole. Define contextual refinement by

`p <=ctx q := forall C m, N(C[p],m) -> N(C[q],m)`.

The proposed central theorem is the exact decision principle

**`p <=ctx q <-> (mustWrite p = true -> mustWrite q = true)`.**

For a self-contained interface, state the completeness direction with an explicit
empty-map witness `e` and `he : e.isEmpty = true`. This uses no additional axiom
and avoids requiring an unselected Std empty-map lemma in the first downstream
source. A later caller can supply the ordinary empty map and its checked fact.
The forward preservation direction does not require that witness.

## Proof sketch using the acquired theory

The acquired characterization is

`N(p,m) <-> (m.isEmpty = false or mustWrite p = true)`.

1. Order Booleans by `b <= c := (b = true -> c = true)`. The characterization
   immediately shows that ordered summaries imply `p <=N q` for every input.
2. Summaries for sequence and choice are respectively Boolean OR and AND.
   Both operations are monotone in each argument. Structural induction on the
   context therefore gives `mustWrite(C[p]) <= mustWrite(C[q])`. Apply step 1
   to obtain contextual preservation, without enumerating executions.
3. Conversely, take the hole context and the empty witness `e`. If `mustWrite p`
   is true, the acquired characterization gives `N(p,e)`. Contextual refinement
   gives `N(q,e)`, hence `e.isEmpty = false or mustWrite q = true`. The former
   contradicts `he`; therefore `mustWrite q` is true.

Failure has a constructive witness, not only a negative Boolean answer. The
only failing summary pair is true/false. For that pair, `N(p,e)` holds and the
acquired `zero_effect_witness q e` gives `Exec q e e`; `he` identifies a concrete
empty result contradicting `N(q,e)`. No new execution search is needed.

## Derived reusable capabilities

- **Complete decision:** decide contextual preservation from two summaries and
  return a proof of preservation or the empty-input failure witness above.
- **Exact observational equivalence:** mutual contextual refinement holds
  precisely when `mustWrite p = mustWrite q`. This is a congruence for sequence
  and choice, so locally proved replacements compose inside larger plans.
- **A small quotient algebra:** modulo this equivalence, sequence is join,
  choice is meet, skip is bottom, and every put plan is top. Associativity,
  commutativity, idempotence, absorption and distributivity follow for this
  observation. The quotient has at most two classes; it has exactly two when
  both `K` and `V` are inhabited, so a put plan exists alongside skip.

For example, `seq p (choose p q)` is observationally equivalent to `p` by
Boolean absorption. The new theorem justifies its use in arbitrary surrounding
contexts with respect to the stated guarantee. It does **not** say that these
plans return the same maps, keys or values. Content-sensitive optimization would
require a different observation and additional theory; no such claim is made.

This extension adds semantic relations, a completeness theorem, a compositional
decision capability and algebraic consequences. It is more than another
instantiation of the original nonemptiness theorem, while needing only ordinary
definitions/proofs over acquired interfaces. Existing contribution, custody and
publication mechanisms suffice in principle; no new network protocol follows.

## Payoff and honest comparison

In a syntactic-tree cost model with unit-cost constructors and Booleans,
evaluating both summaries takes `O(|p| + |q|)` operations. Once those exact
summaries are locally computed or checked and cached, the comparison is `O(1)`.
It does not traverse possible contexts. In contrast, direct enumeration of
independent choices can require exponentially many execution paths: a sequence
of `k` binary choices has `2^k` branch traces, even though some final maps may
coincide. This is a rigorous benefit over enumeration, not a lower bound on every
alternative algorithm and not a new complexity improvement over `mustWrite`
itself. The new capability is its proved completeness for contextual refinement.

An equally optimized local library is allowed to know and use the same abstract
interpretation. Such a library receives no inherent algorithmic disadvantage.
The network's possible benefit is transferring this derived capability to an
agent whose initial library lacks it, reducing repeated discovery and proof
construction. For matched starting knowledge and recipients, a positive region
requires a full-cost inequality such as

`C_create_once + C_publish + C_service + sum_i C_acquire_check_use_i`
`  < sum_i C_independent_derivation_and_use_i`.

Specify the common initial-library costs on both sides and count the origin's
creation once; do not double-count it as an additional receiver derivation.
Search failures, custody, publication and later checking belong in the relevant
terms. If the local baseline already has this theory, derivation savings can
vanish and sharing may lose. No causal network speedup, sustained growth or
experimental benefit is established by this proposal alone.

The economical next implementation decision, after the parent theory is actually
accepted, is whether one downstream agent should acquire its unknown interfaces
and prove this extension through the existing route. First settle that workflow
and exact dependencies; do not create another broad benchmark or new generator
merely to illustrate the theorem.
