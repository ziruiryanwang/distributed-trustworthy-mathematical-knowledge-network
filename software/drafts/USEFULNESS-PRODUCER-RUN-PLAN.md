flag. Although `node.py` supports owner-configured initial offers, editing a
generated config is not the documented configure path. The frozen vocabulary
node must not be renewed, exposed or otherwise mutated.

fresh init; reproduce the exact frozen vocabulary by submit/publish; admit that
newly published candidate; submit/publish the independently authored append/fold
lemma. The extra vocabulary reproduction is disclosed preparation, not new
mathematical authorship. It requires no service, discovery, find, inspection,
custom scenario harness or product change.

stages/424 MiB: init, find, admit, lemma submit, publish. It needs a separately
reviewed prospective owner-config authoring path or a narrow configure extension,
and an exact raw vocabulary-package copy inside the new readable domains.
It is not silently authorized here. An offer is a candidate, never acceptance.
