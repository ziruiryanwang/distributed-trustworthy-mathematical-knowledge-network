## New worker-only fault seam

`NativeObservation` captures the genuine installed `run_stage.Job` through a
small explicit runner adapter. It returns that same unmodified object and
does not change limits, stats, cleanup or installed modules. A local Transport
subclass calls the original output-bound check first, then invokes the observer;
base launch, exception handling, quiescence and receipt persistence remain
unchanged. A post-trigger callback is explicitly a no-op observation, not a
second exception injection.

The observer checks only the known stage-1 path, authenticates its fixed source
and complete submission plan, observes the actual RUNNING first Lean command,
opens its process handle, checks the pinned executable image and membership in
the exact original public Job, repeats the stage snapshot and performs a
zero-time live-handle wait. It then throws one fixed fault into base cleanup.
The 600-observation/30-second gate is checked at entry and again before the
final wait/trigger; the selected receipt has at most two 256-KiB reads per
observation. Partial JSON/missing-file counts are retained without an inner
retry loop. Oversize, unsupported, missed-window and Win32 failures cannot
become positive triggers.

Every candidate process handle is checked closed. The selected handle remains
open through base cleanup, is checked signalled afterward, then is checked
closed in a finally path. Any close/cleanup/persistence uncertainty stops the
qualification. Supplemental evidence preserves the observed stage bytes and
binds request, plan, worker and **actual original receipt** hashes; no original
receipt is rewritten. The hook's trust/pinning belongs to the outer worker,
not an invented thirteenth original-call pin.

Early independent source review identified three details repaired before this
handoff: recheck the observation deadline near trigger; compare the unchanged
ordinary supervisor's settle value **15 seconds** (recovery explicitly uses
5); and bind the supplemental hook record directly to the original receipt pin.
Those source observations are not runtime qualification.
