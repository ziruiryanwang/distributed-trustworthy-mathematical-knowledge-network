The favorable example uses distinct monomorphic record interfaces and explicit specialized helper types. Token queries discover their identifiers rather than receiving them as inputs. Full native correspondence, actual source evidence and resource sufficiency remain premises, not generated artifact claims. It is possible that solving the original B example directly is cheaper; the checkpoint does not assume a sharing advantage.

Two failures sharply limit the result:

- A constant map from Bool/NAND to Unit preserves the operation and satisfies a true image associativity theorem, while Bool/NAND associativity fails at the stated assignment. Without checked equality reflection, VIEWS1 returns only explicit image/forward partial work or a missing-witness outcome, never the false original equality.
- A common folded helper type such as `Function.Injective f`, a generic carrier/dictionary interface or a raw wrapper can hide the B-domain feature or fail the fixed templates. This profile selects no free unfolding, generic elaboration or fallback index. Publishing a specialized checked wrapper is optional real work with its own evidence/retention/index costs.

Irrelevant prefixes, missing helpers, long telescopes, feature truncation, unused binders, unfamiliar proof realizations and large cold closures can also defeat the heuristic. Such failure is not global mathematical absence or falsehood. These limits belong in the success denominator of any later evaluation.
