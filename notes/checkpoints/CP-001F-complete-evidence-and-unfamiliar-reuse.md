# CP-001F: complete evidence and unfamiliar-agent reuse

Date: 2026-09-20. Status: integrated concept/specification checkpoint with independently reviewed mechanisms and explicit qualification boundaries. This is not a software release or a declaration that the ultimate goal is complete.

## Purpose

Make the decentralized Lean mathematical commons operable at the places where valid local mathematics must become affordable reusable knowledge for independent, initially unfamiliar agents. Correctness remains separate from discovery, usefulness estimation and private research choices.

No code, executable model, Lean replay, build, artifact extraction, exploit execution or benchmark was performed. All work is concept/specification, read-only source inspection, argument, arithmetic and independent audit.

## Start here

Read [Operational corpus v3](../../spec/OPERATIONAL-CORPUS-V3.md), the [audit disposition](../audits/CP-001F-AUDIT-DISPOSITION.md), and its named detailed notes. Frozen [v2](../../spec/OPERATIONAL-CORPUS-V2.md) supplies unchanged mathematical, authority, transfer, indexing and custody contracts.

The product remains initially Lean 4 based, with independent local investigators and no necessary central server, compulsory theorem ledger, shared research objective, human-intention assessment or unsolved-mathematics task registry. Heuristics and learned tools may guide useful work; they cannot supply mathematical acceptance.

## Main advances

| Operating problem | Selected mechanism |
|---|---|
| Ordinary Lean imports can omit real proof bodies | Full-data producer collection using explicit global-private imports or completed per-module capture; receiver checks inert exported evidence independently |
| Independent proof choices can collide or expand badly | Precisely restricted checked proof capsules, complete canonical background guard, unchanged exact witness rules |
| Regular-zero native hints can amplify repeated conversion | Deterministic HEIGHT1 under NativeRules code 3 and a new FoundationID |
| Connected communities can still fail to discover each other's work | Bounded iterative ROUTE1 provider rendezvous with explicit routing/service roles and sharded expiring metadata |
| Broad provider catalogs can force linear exact-query search | Finite explicit FULL_EXACT coverage, actual exact-key memberships and counted provider-holder lease groups |
| Foundations change during long-term accumulation | Local incremental MIGRATE1 with exact transformation context, independent target checking, honest correspondence grade and separate source/target custody |
| Validity and service counters can disguise poor usefulness | Separate provider discovery, candidate return, checked application, cost and scoped-growth observations |

## Rigorous evidence

The new notes include a fully honest connected-network discovery counterexecution; a coarse-index ownership indistinguishability lower bound; a source-size versus literal universe-substitution expansion family; an exact eligible sharing-preserving capsule recipe; source-backed unfolding and full-evidence import analysis; explicit routing/group/migration state and resource contracts; and independently checked queue/index-cost arithmetic.

Three collaborators performed complementary investigations and cross-audits. Concrete review findings led to changed eligibility, lookup termination, cache binding, identity/version binding and cost statements. The final [disposition](../audits/CP-001F-AUDIT-DISPOSITION.md) records which findings were repaired and which claims remain outside established scope.

## What completion would still require

This checkpoint is not proof that the ultimate autonomous-accumulation goal has been achieved. Broad practical source-to-native compatibility, difficult branch joins, structural retrieval utility, sustainable resource allocation and actual fault/throughput behavior are not established by paper arguments or hashes. The specification must keep addressing concrete gaps, and future execution requires the user's implementation authorization.

No guaranteed exponential mathematical novelty, universally complete search, permanent survival under arbitrary resource loss or absence of every unknown software defect is asserted. The high bar remains trustworthy contributions and genuinely effective reciprocal mathematical use.
