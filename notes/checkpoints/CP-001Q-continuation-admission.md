P's independent B node ends with 480 selected targets, 24 pending twenty-target scopes and genuine continuing custody/service duties. Q must import that state. It cannot obtain room by resetting the calendar, renaming a pending pool, copying a grant or assuming that a planned release already happened.

The controller is selected because it specifies how to make the next local decision and how to retain its unfinished obligations. Four additional targets are a small nonempty witness for that procedure, not a substitute for a sustained-growth design.

## Controller contract

1. Inspect a bounded candidate cohort under actual preparation, native-checking, staging and disposition authority. Distinguish mathematical validity, local nomination and funded public selection.
2. Inventory exact current logical, physical, owner/borrower, custody, incident, unresolved-outcome, spent-work and deadline state. Reserve incumbent service and funded aftercare before optional work.
3. Preserve an existing partial handoff. Otherwise freeze pending inputs in stable local order and construct O's finite partition/carry plan against actual occupied tiers. Prefer the oldest two unprocessed inputs; use bounded first-step windows if that block does not fit. Fallback partial-step frames do not publish newcomers.
4. Test a prescribed schedule with resource vectors and all-prefix stock constraints. Four desired copies do not bound extra/uncertain placements, markers or retained generations. Unknown actual obligations cause nondecision.
5. Credit only actual, unique, post-base-cut physical releases of charged allocations. Recut the stock origin at a release barrier; never subtract a release already reflected in the new starting stock. Work accounting separates spent amounts from unspent residual reservations.
6. Complete the committed old-progress prefix before new public selection. New publication still requires independently checked evidence, ACTIVE custody and current complete-closure public authority before index/routing work.
7. Recheck actual state, charge failures, retain unfinished work and make the next admission decision before the current funded suffix ends. Grant expiry does not release durable custody pins. Future supply remains a real requirement.

These steps use local dispositions and existing paid operations. They create no mathematical task list, human-intention acceptance test, remote resource entitlement or proof of global capacity. Heuristic nomination remains allowed but cannot change proof validity.
