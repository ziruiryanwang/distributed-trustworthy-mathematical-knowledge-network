N1 is a necessary precision improvement, not a claim that the previous phrase compelled an unsound implementation. A content-collision or decoder incident on a witness-map page must not receive false-negative clearance merely because that page is not a theorem declaration. Broad or uncertain affected scope still requires a conservative breaker.

X1 corrects an actual asymptotic claim boundary. Suppose N sorted keys are packed into fixed full consecutive leaves. An insertion before the first leaf changes the membership of every subsequent full leaf. Their content hashes and affected parents therefore change even though only one mathematical entry was added. Repeating such updates can yield quadratic newly stored inventory metadata. A deterministic layout is not automatically an incrementally stable layout.

The repaired inventory instead uses exact fixed 37-byte keys and branches only at key-bit divergence. Conditional on retained verified subtrees and an independently established exact k-entry delta, at most O(kL) nodes are copied for L = 296. Obtaining the correct closure/delta is a separate operation. Unknown snapshots and cold imports still require full bounded derivation/verification. With N entries the inventory has 2N-1 logical nodes; the audit explicitly rejected keeping the old 517-page example after this change. Native map updates can also induce O(L squared) operational-inventory node changes in a chain example; there is no blanket O(L) bound for every downstream structure.

## Native argument checks

### Identity and canonicality

The fixed key representation is injective over the selected identifier domain: algorithm, type, schema, and complete digest are present. It is not a shorter alias or an extra hash that loses the declared kind. The binary Patricia topology is uniquely determined by first differing bits and nonempty zero/one partitions. Prefix lengths, zero padding, child types, strictly increasing split positions, leaf types, and actual descendant bounds are checked. Node count and native dependency depth remain distinct quantities.

Direct SemanticContext references are recomputed from the actual statement telescope and conclusion. Member selectors and universe instantiations remain in native term identity even when the context set stores only the owning declaration/group ID. Exact transitive meaning remains recursively bound by immutable references; selected proof auxiliaries do not enter statement identity merely because a proof happens to use them.

### Evidence-map completeness and warm reuse

Replay2 derives native reachability rather than trusting a copied declaration list. The expected JudgmentID-to-ProofID map is reconstructed from actual reached references and compared with the canonical submitted root. A supplied map count or a subtree's apparent size cannot conceal an extra selected witness. Missing data yield nondecision; a missing selection, cyclic support, or wrong proof-to-judgment association cannot be installed as a theorem assumption.

The warm-certificate union rule preserves that distinction. Each child certificate binds a complete selected closure under its exact checker/decoder/interpretation view. Equal-key unequal-value witness conflicts reject an assembly. The native environment must match those selected assignments; equality of printed theorem types does not justify silently using a different proof basis. Arbitrary native environment joins and arbitrary trie unions are explicitly not claimed constant cost.

The chain bound is therefore conditional on retained compatible predecessor certificates/environments and small witness changes. It is not a cold verification bound or an exponential mathematical discovery theorem. The note separately acknowledges native kernel work, changed witness information, and expensive conversion.

### Current reliance, faults, and byte protection

Relevant guard revalidation is scoped to the selected basis, policy/checker/interpretation state, actual byte protection, and complete incident coverage. An unrelated global commit need not trigger a retry. Missing journal coverage cannot be interpreted as no incident; a slow reader must recompute from a complete current view or return UNKNOWN. Expensive scans remain outside the bounded final writer boundary, while intervening relevant changes must still be covered before a positive commit.

The expanded exact support summary closes the binding-page ambiguity. General or unresolved faults trip a conservative breaker rather than waiting for full descendants propagation. Root/DAG protection avoids repeated leaf repinning only for already established protected shared subtrees; cold protection and last-owner deletion can still touch large graphs and require their own funded work. Physical loss is not repaired by an old reference count.

### Native widths and foundation separation

The added Native2 width table appropriately separates resource tuning from interpretation. A uint64 wire field does not acquire native u32 representability merely because a receiver grants more memory. Projection fields, binder indexes, native unsigned counts, array/member indexes, and derived sizes need checked conversions and semantic bounds. Ordinary mathematical Nat values remain arbitrary precision rather than being incorrectly restricted to the index domain.

The note also correctly observes that a short term can compute a dangerous large native arithmetic operand. A surface literal-size cap is not a proof that every internal primitive is safe. Isolation and timeouts produce nonacceptance on failures, but cannot convert a known-unsound native path into a sound acceptance rule. Foundation/security qualification remains substantive.

## Discovery and local-agent argument checks

### Retrieval is not premise discharge

REUSE1's candidate and tentative-match outputs are distinct from a checked local application. Actual dependent argument types, universe instantiations, unresolved premise proofs, and transport/congruence evidence are checked before a completed application claim. A matcher is not assumed to decide general theorem applicability or solve arbitrary residual premises. This respects the corpus-first scope: a transient local retrieval expression is not a compulsory shared research goal or unsolved-problem registry.

Exact interface divergence is handled through reuse of the same exact interface or explicit checked adapters, not source aliases. The note's m(m-1) possible directed conversion count is a translation-work illustration, not a claim that all theories are mutually translatable. Popularity and syntactic downstream edges remain bounded ranking signals; the unused-argument padding counterexample correctly shows they are not necessity certificates.

### Nonprefix windows and finite snapshots

FIND_WINDOW uses an explicit public-ID lower boundary, immutable predicate/planner/snapshot binding, and an inclusive lower-bound seek. It records the next unprocessed item rather than merely the last returned match. An interrupted test or a match that does not fit the output remains unprocessed. There is no silent wrap or implication that an END result inspected entries before the chosen start.

A new paid query may use a still-live old-origin snapshot under the exchange proposal's admission-generation seal, but cannot extend its original lifetime or revive an old CALL. This is compatible with the scope/holder checks. It does not fix scans longer than the actual snapshot lifetime; changing snapshot origin semantics and changing query planning are different mechanisms.

Rotating hash-space boundaries are correctly labeled heuristic rather than uniform record sampling. The low-density relevance and sparse-contact examples state their sampling assumptions. The finite directory horizon, source/interface coverage, and missing structural features remain genuine discoverability limits even when imported mathematics is sound.

### Advisory capability boundaries

ADVISORY_READ1 names one explicitly disclosed manifest and its finite typed members. Its manifest is directly in scope without listing its own hash. Arbitrary referenced mathematical IDs, contacts, profiles, or other advisory roots do not enlarge the scope. Native payload acquisition still requires a native-root/export capability, and instance/rewrite activation remains a receiver-local bounded choice.

The shared interface is consistent with BUNDLE1: optional negotiated root hints stay within HELLO limits; actual payloads require a funded call and delivery, exact hashes and lengths, aggregate cache limits, and a disclosure-version recheck. Executable code, filesystem directives, dynamic native imports, and instruction authority are not conferred by a naming bundle. The resolved O1 clarification makes the staging/use distinction explicit without loosening these safety boundaries or requiring bulk import of every guide target before useful tentative routing.
