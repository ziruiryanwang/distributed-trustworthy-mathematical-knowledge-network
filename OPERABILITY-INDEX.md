# Democratization of mathematics: operational concept index

Latest concept checkpoint: CP-001D, 2026-09-19.

A Lean 4 based decentralized commons for independently generated, independently checked, reusable mathematics. Local agents investigate outside the corpus. No human-intention layer, shared root goal, or unsolved-mathematics task registry is required.
