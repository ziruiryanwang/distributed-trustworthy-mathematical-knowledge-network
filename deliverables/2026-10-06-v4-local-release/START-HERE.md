## What this release does not claim

The checked associative-squaring law justifies `2^r-1` versus `r` multiplication
calls for two specified algorithms. This is useful, precise theoretical evidence,
not exponential network knowledge growth, a shipped optimized evaluator or a
universal usefulness score. The software's actual production and receiving
checks have separate measured costs.

The final actual receiving check used 18.25 seconds of whole-child-Job CPU,
plus 0.8125 seconds of separately observed launcher CPU, and about 22.81 seconds
of public wall time through cleanup. The outer PowerShell monitor's CPU is not
included. This is one restricted theorem, not a universal checking bound.

Current mathematical support is restricted, not arbitrary Lean/mathlib. Peer
discovery is bounded and contact/shard-based, not a maintained global DHT. Network
tests and relocated-package qualification are same-host, not independently
hosted or clean-machine deployment. These remain central
technical limits, not attribution questions to be addressed first.

Project licensing is still undecided. This is a local delivery to the project
owner; it has not been externally published or deployed. Review redistribution
obligations before public release. The final results and integrity audit, not
the version label or a successful archive extraction, define qualification.
