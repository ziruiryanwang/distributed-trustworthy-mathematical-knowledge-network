## What changes

This is the same decentralized Lean 4 framework: local agents discover inert
candidate packages, verify them locally, reuse admitted mathematics, and
contribute results. No central acceptance server, global research agenda,
human-intention acceptance test or bundled autonomous agent is required.
It is not an already populated representation of all mathematics.

Source10 changes three of 114 payloads; 111 are identical to source09.
`py/codec.py` directly appends short canonical headers; `py/source_codec.py`
updates its embedded codec pin; `assets-lock.json` updates those two helper
rows. Validation, canonical bytes, foundation, Lean checking, peer protocol,
database/configuration and resource policies are not intentionally changed.
[RESULTS.md](RESULTS.md) separates measured component improvement from scoped
installed qualification. The benchmark does not establish whole-agent speedup.

## Start after confirming delivery integrity

Use Windows x64, PowerShell 7, fixed local NTFS/non-reparse directories and
exclusive cooperative-owner control. Supply the complete Lean 4.34.0 Windows
runtime and qualified Python 3.14.6 distribution separately (SQLite 3.50.4,
OpenSSL 3.5.7 with TLS 1.3/ALPN). Invoke Python with `-B -E -s -S`.
The inherited [environment report](../2026-09-23-v1-local-candidate/RESULTS.md#supported-environment-and-trust-premises)
records runtime pins; these are not whole-runtime attestations or clean-machine
qualification. No dependency downloader is included.

1. Verify the saved package against this source10 table using PowerShell
   `Get-FileHash -Algorithm SHA256 -LiteralPath <absolute-path>`. Read the
   verified archive's unchanged `TLS-WALKTHROUGH.md`; follow its exact
   extraction/payload verification/build recipe using these new package pins.
2. Choose fresh, separate install/state/scratch/build-work directories. Supply
   the documented space margins (default node check: at least 5 GiB + 64 MiB,
   excluding additional runtime/build/second-node needs). Generate new owner
   identities; do not copy test keys, old databases or experimental build output.
   Resolve the real PowerShell 7 path with `Get-Command pwsh`, replacing examples.
3. Configure and initialize through the public interfaces. Give local agents
   `AGENT-QUICKSTART.md`, `API.md`, their context/snapshot and authorized peers.
   The request helper creates files; `manage.py request` performs the operation.
   `HOSTING.md` documents separately funded finite service; exposure alone does
   not start hosting. Require documented structured command results.
