the selected nested Rose group. But the attempted successor safely refused

kernel membership did not imply that ordinary source could name the constant.

group descriptions. It was a product source-interface defect, not a false
theorem or a request for the author to weaken the intended contribution.

already-checked missing recursor through Lean's own asynchronous-constant API,

canonical inventory through frontend lookup. Missing nonrecursors or
