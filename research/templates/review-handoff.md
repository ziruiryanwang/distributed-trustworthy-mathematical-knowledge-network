# Bounded author–reviewer handoff

Optional project-research checklist. It is not a protocol for mathematical agents in the future commons.

## Assignment

- Question and open issue it closes.
- Exact inherited sources; owned output path; other paths read-only.
- Explicit exclusions and exit criterion.
- Independent reviewer and downstream consumers affected by a change.

## Preflight

Send the smallest concrete contradiction early: source passage, failing state or inequality, affected claim and possible repair. Coordinate shared findings between reviewers, but preserve each reviewer's independent judgment. A partial draft is not a final audited cut.

## Held cut

Author supplies complete source path, byte length and SHA-256, then stops editing. Root confirms both reviewers have that same cut. Each reviewer checks the full assigned scope and records assumptions, findings and excluded stronger claims. Hashes identify bytes, not correctness.

## Repair

Root consolidates overlapping findings into one repair request. Author releases one new held cut and identifies substantive changes. Affected reviewers reread the full relevant composition and independently record closure or the remaining failure. Never silently carry an old PASS to changed premises.

## Integration

Root states precisely what would be selected, what remains hypothetical, and which consumers need readmission. A fresh reviewer checks consequential selection/composition where useful. Freeze coherent evidence only after closure; leave navigation and ownership records mutable. No paper audit can mark an unexecuted qualification gate passed.
