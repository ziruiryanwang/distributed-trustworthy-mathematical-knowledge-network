## One implementable layout and prerequisites

Use separate ordinary sibling roots in an operator-selected deployment:

```text
app/receiver/       exact receiver597 files, unchanged profile
app/peer/           exact selected nine-file peer/search source
app/contributor/    optional exact contributor12,396 files, unchanged profile
app/tools/          optional separately pinned standalone owner-TLS helper
owner-config/      new local configuration, never inside immutable roots
state/             new selected shard; no shipped SQLite database
inputs/            local source and acquired inert bundles
operations/        fresh receiver/contributor work; preserve failures
private/           freshly provisioned owner credentials; never distributed
```

Base ZIP carries receiver and peer; add-on ZIP carries contributor only. Handoff,
archive/file manifests and current qualification notes stay outside the exact
receiver/contributor roots. Their frozen internal docs stay byte-identical even
where they contain historical pending wording or research paths in prose.
Do not rewrite profiles: their role, PATH and Lean-path entries are relative.
The receiver/contributor derive their installation root from the profile parent
and require the launched Python/script to be the roles inside that root.
Peer modules load helpers relative to their own file; they can be launched by
the receiver's bundled Python as a separate process.

Prerequisites are Windows x64 and ordinary owner-controlled non-reparse paths
on a compatible filesystem, Windows system DLLs, space for installation,
archives and separately budgeted operations. The contributor profile permits
up to12GiB operation storage and4GiB worker memory; these are ceilings, not
small observed requirements or disk reservations. No system Lean/Python/Cargo
installation or administrator/network installer is required for these binaries.
Copied runtime behavior on another host remains unqualified.

Actionable command templates after independently checking archive and profile
pins (absolute paths required; these are documentation, not launch selections):
