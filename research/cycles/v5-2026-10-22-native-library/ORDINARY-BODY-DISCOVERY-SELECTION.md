# Selected change: discover vocabulary, then methods

2026-10-23. Root source selection above Git `e61706b`. Full v5 remains active.

## Product decision

A local agent has a formal preservation premise but does not know a peer's
`Stable` abstraction. First retrieve a definition by a bounded fingerprint of
its body; then use the newly learned exact symbol in the existing theorem index.
The agent chooses the local formal property. There is no human-intention input,
global research agenda or compulsory query planner.

The ordinary installed reciprocal workflow is already independently audited.
Do not repeat it. Its broad theorem query is the defect addressed here, not
mathematical acceptance. The proposed beta/delta reducer is deferred: it adds
implementation risk before proving that simpler vocabulary search is inadequate.

The design and independent challenge are recorded in
`ORDINARY-APPLICABILITY-DESIGN.md` and `ORDINARY-APPLICABILITY-REVIEW.md`.
Use their revised two-stage body-fingerprint proposal, not the original reducer.
Existing type-pattern and conclusion-fingerprint mechanisms have been inspected;
reuse their bounded path-observation and local-telescope contracts, adapting only
the ordinary DAG representation. Existing postings, authenticated snapshots,
bounded query/session machinery and exact evidence acquisition remain in use.

The body record binds the exact full portable V2 singleton definition evidence,
not the old proof-free type preview (which has no body). Its exact export locator
still identifies the target; `object_sha256` and `object_bytes` describe the full
evidence. Stage two uses the unchanged ordinary preview adapter. Resolving a
body candidate must rederive its record from its exact evidence. Syntax and
hash correspondence never confer mathematical authority.

The source prefix strips only leading parameter lambdas. The consumer strips
only an explicitly counted local-context telescope. Goal-internal binders remain
internal. Scope-aware path tokens and bounded STAR query alternatives reuse the
prior fingerprint principle, not an unbounded matcher. Exact profile/path order,
byte/node bounds, singleton descriptor/inventory agreement and refusal behavior
must be fixed in source and reviewed before execution.

## Decision-changing evidence

Select only one small metadata-only check after source review: role/scope and
context-boundary controls; malformed/tampered evidence rejection; deterministic
query bounds; actual retained Stable definition against an independently spelled
local preservation premise; and two-stage real-index retrieval among diverse
decoys. Include genuine collisions rather than pretending three path tokens
decide equivalence. Use existing accepted evidence; no new Lean build, foundation
check, catalog mutation, provider deployment or certificate production.

Expected benefit is lower selected posting work for this operating class, not
an unconditional asymptotic search guarantee. First-stage definition ambiguity
and second-stage symbol degree both count, as do failed candidates and both
queries. Stop or revise if the profile fails its chosen discriminator; do not
grow it into a new normalization/proof-search engine by inertia. Runtime is not
authorized by this source selection and needs its own finite recorded envelope.
