## Acceptance argument

1. **Retained authority is exact and local.** The old admission selection and
   its controller/evidence/catalog sources are digest-selected. Native support
   reconstructs the original profile from its retained support files and permits
   only the selected compiled module census. New module-enabled authoring
   helpers do not replace the receiver. The fixed parent has four roots and
   3,622 bound names.
2. **Frozen state is not opened mutably.** The original adopted catalog is
   checked against the selected seven-file/six-directory manifest, fixed database
   hash and identities. It rejects aliases/unexpected entries and withdrawal,
   locks the original owner byte, stream-copies to fresh destinations and checks
   source plus readback hashes. Only the new copy is opened by `LocalCatalog`.
   The original failed reservation and operation directories remain preserved.
3. **Bundle labels do not manufacture imports.** Every prepared name/ID must
   equal the actual parent binding. Every bundle boundary must additionally be
   in that prepared map. New-unit imports are independently derived by
   `inspect_unit`, then resolved only through those boundaries or earlier new
   units. Same-named unbound parent symbols, output overwrites, duplicates and
   forward references fail. Exact new evidence is canonicalized and reparsed;
   no new theorem proof is erased. Incidental literal support is not falsely
   added as a serialized direct import.
4. **Reservation is distinct from checking.** One existing `reserve_extension`
   call reparses the exact evidence and binds the batch request hash. The actual
   unchanged worker receives the selected parent plan, new units, live reserved
   root and exclusive fresh artifact/report destinations. It restores retained
   snapshots and checks the new extension; old theorem evidence is not replayed.
5. **Commit is behind the actual event.** Zero worker exit alone is insufficient:
   `clean_worker` requires child reap, Job closure, no cleanup/termination errors
   and zero active or terminated processes. New PANIC diagnostics refuse
   promotion. Input and original-store verification precede the exact report
   checks for schema, extension kind, module/root, parent, names, unit count and
   actual artifact size. Only this path calls `_commit_checked` with the live
   grant. Its existing artifact/inventory and transaction checks remain intact.
6. **Final claims are appropriately narrow.** Exact final bindings are compared,
   the catalog is closed/reopened and compared again, and inputs/original store
   are reverified. Reopening is persistence evidence, not another kernel check.
   A later failure cannot undo a real prior commit: the controller does not
   automatically replay, and its `finally` abandons only a still-active grant
   in an open catalog. Uncertain or postcommit failure requires inspection.
