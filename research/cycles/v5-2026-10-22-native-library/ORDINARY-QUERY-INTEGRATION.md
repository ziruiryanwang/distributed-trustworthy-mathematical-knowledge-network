# Coherent ordinary query and theorem-reuse integration

2026-10-23. Root source selection; not a runtime or release claim.

## User workflow and payoff

A local Lean project writes a formal contract without first finding a theorem
name or supplying a proof. The local command emits its type; a pure command
binds already known portable symbols and produces the feature specification
accepted by the existing peer search. A received, locally warranted result can
then become an ordinary project module even when its proof uses an exact
already installed singleton theorem. These remove two demonstrated workflow
obstructions. They do not establish general theorem search or useful growth.

Keep the existing owner, peer protocol, admission, storage, supervisor and
extractor. Certificates are not required. No new database or agent strategy.
The new search namespace is explicit: old indexes are not silently migrated.
New indexes must be populated through normal publication; reindexing is a real
operator cost. Ordinary source/package sharing gets the same query facility.
