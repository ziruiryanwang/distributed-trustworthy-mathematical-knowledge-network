## Consequential source argument

caller UTF-8 source bytes and caller-selected distinct output names. Acquired
and output arrays are bounded by 32 entries and 64 KiB; source is at most 1 MiB,
valid UTF-8 and NUL-free. Encoded names, not dotted display strings, determine
identity. Acquired ExportIDs are recomputed; every requested output must be
absent from the protected selected context before native authoring.

Existing request preparation is reused. All acquired symbols must match that
context and local exact locator/evidence bindings. Empty acquired sets use the
real protected basis `Eq` symbol only to satisfy existing nonempty request
syntax, not an artificial research task or evidence acquisition. Definitions
retain necessary semantics; existing accepted theorem authoring handles avoid
proof-only ancestry under the unchanged request rules. The helper neither
initializes an owner nor silently acquires or accepts new dependencies.

The fixed scratch source imports Init and selected meta wrappers, enters a
public section, constructs the selected request, inserts the exact caller bytes
and exports the exact output-name JSON file. Caller names are not interpolated
as Lean syntax. ASCII filesystem paths remain an explicit initial restriction;
declaration names may be UTF-8. Source is approved executable owner code, not
hostile peer input; resource supervision is not a security sandbox.

The new Lean wrapper reads at most 64 KiB of target names, requires 1–32 distinct
names in the current owner module and outside the prepared boundary, and admits
only safe/nonpartial definition or theorem records as requested targets. It
delegates the full selected dependency closure to unchanged `selectedDeferred`
and uses the unchanged V2 candidate serializer. Generated dependency groups are
not split. This does not qualify arbitrary inductive declarations as requested
top-level outputs.

One immutable `AuthoringProfile` binds the installed core manifest, actual
loaded Python helper files, author worker and all files reachable in the selected
helper directories. Its bounded census and byte hashes run before and after
authoring. Core module-object identity checks prevent accidentally mixing helper
imports with another ordinary evidence interpretation. Installation/runtime
integrity and nonhostile local storage remain explicit premises; the profile is
not a hostile-process race defense or another mathematical certificate.

One original parent allocation spans preparation, source execution, binding,
admission and output retention. Authoring CPU is charged before another operation
budget is requested; admission CPU is charged in `finally`. New stage budgets
must be fresh and end no later than the parent deadline. The actual caller
derives them from remaining parent wall/controller/native CPU, not full renewal.
The generated source, request files and target file are read back exactly after
the clean authoring event. A compiler success never grants acceptance.

Binding uses the same complete expected output list and protected context.
Unresolved interpretation names now appear explicitly in the structured failure
report; preflight missing dependencies appear as exact name/ID rows. No lookup
failure changes a claimed identity, fetches trust automatically or retries work.
Only the installed ordinary preflight/admit path grants new mathematical warrants.

All requested outputs are mapped to exact admitted units and get individually

acceptance through the unchanged admission contract. If preview/publication or
logging subsequently fails, `ContributionError.report` retains a detached accepted
