## Why acceptance remains sound under the same assumptions

Let K be the actual protected accepted context, P the authenticated prepared
map, C the candidate's explicit name/ID claims, U its unresolved names, and N
its complete new declaration units. Resolution establishes:

1. For every `(n,s)` in C, both `P[n] = s` and `K[n] = s`.
2. Every name in U is absent from P and C, occurs once, and has an exact
   binding in K. No candidate-supplied symbol ID is accepted for U.
3. Each new unit's external-reference census, independently recomputed from
   its inert declaration and complete inventory, is resolved in those bindings
   or in outputs of earlier new units. New outputs cannot overwrite K.
4. All N are submitted to the unchanged actual native checker under K.
   Commit requires the actual successful clean invocation, exact report,
   expected names/artifact and live private grant, then reopen verification.

Consequently this seam introduces no premise that the authoring environment A
equals K. A name can have different authoring and receiver meanings. In that
case the complete N either checks under K or is rejected. Accepted statements
have K's formal meaning; preservation of author intention or A's meaning is
not asserted. Imported safe records and scratch signature axioms only guide
candidate construction/serialization. They do not add receiver axioms.

## Scheduler and group boundary

The shared `stopAt` checks static names first, otherwise memoizes **both** true
and false dynamic answers for an immutable owner environment. Each distinct
nonstatic lookup consumes the finite lookup budget; positive answers consume
the finite combined static/dynamic name budget. The predicate validates name
policy before point lookup. It does not enumerate all owner declarations.

`BootstrapProbe.owner` normalizes constructors and recursors to their atomic
inductive owner. `makeUnit` retains actual referenced names in `unit.refs`,
while edges use those normalized owners. The new scheduler handles both:

- A stopped actual member is recorded as the actual import name. A stopped
  normalized owner cuts its edge without fabricating an extra actual import.
- If a nonstopped member has a stopped owner, traversal refuses a partial
  boundary. If a stopped member's owner were not stopped, attempted export of
  that group would refuse when its emitted member hits the boundary.
- New emitted names cannot overlap any stopping boundary; complete generated
  groups remain atomic. Actual current-module new groups are still checked
  and serialized completely, with the existing bounded lazy group census.
- Internal group references, excluded from dependency edges by `makeUnit`,
  do not create artificial cycles. New-unit ordering remains the existing
  bounded Kahn traversal with complete closure checks.

With `dynamic = none`, `stopAt` is exactly static-set membership; the old
entry points retain their static stopping and complete-new-unit behavior.
The explicit added group-member check can reject an invalid partial boundary
earlier, not accept one that previously failed. `selectedAbove`,
`selectedInterpreted` and the old bundle schema remain separate old routes.
The unused old `schedule` helper is redundant source, not an authority bypass
or a reason to expand this task into cleanup.
