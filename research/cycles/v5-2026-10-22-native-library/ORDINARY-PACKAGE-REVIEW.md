  source, acquired meanings, output names and fresh output directory. It does
  not copy an owner, replay a basis, infer a parent, retry failures or publish
  remotely. Keep output disjoint from package/runtime and catalog/custody roots.

  Owner-approved Lean source is executable code, not a hostile-input sandbox.
  Normal catalog reopen may settle stale RESERVED operations; status through
  that API is not a strictly mutation-free SQL observation.

These are implementation-boundary checks, not requests to redesign certificates,
