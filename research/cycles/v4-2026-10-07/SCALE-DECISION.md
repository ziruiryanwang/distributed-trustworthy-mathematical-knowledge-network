not exponential DAG expansion inside one capsule. Avoid promising that module
IDs make conversion, flattening or certification constant cost. The complete
selected semantic closure is still real work. Every agent need not store all
modules, and no acceptance step needs a census of the global corpus.

## Required data/assurance invariant

Let `id(v)=H(domain || canonical(v))`. A selected module descriptor binds the
policy, exact local definition plan, direct dependency IDs and exact referenced
declaration identities. Never infer type equality or mathematical validity from
its identifier, source alias, provider or popularity.

The resolver returns a finite DAG `G=(V,E)` only if every demanded ID resolves
to exact canonical bytes, every listed edge resolves, duplicate IDs have equal
bytes, dependency cycles are refused and every operation-wide bound holds. It
must avoid a self-hash cycle: local aliases/declaration ordinals are not a module
ID embedded in its own preimage. Selection is from the requested root only;
unreferenced store content is neither read nor trusted.

Lowering must preserve the bound association between every dependency and the
definition it replaces, reject foreign policies, free variables/universes,
reserved-name shadowing, undeclared/missing imports and conflicting declaration
names. It should not beta-normalize merely for deduplication. The emitted
capsule must be F-closed and checked through the unchanged adopted final native
or guest relation. A compiler receipt/report is not mathematical evidence.

The conditional correctness argument is compositional: hash binding supplies
the selected bytes, finite topological lowering substitutes those bytes under
the reviewed universe/name rules, and the genuine final check accepts only the
actual emitted mathematical object. **Final correctness does not require an
untrusted lowering algorithm to be sound.** A lowering error may instead produce
the wrong well-typed object, so the exact source-to-output compilation record
and module identity must not be advertised as proof of intended meaning without
the separate structural substitution argument. No human intention enters the
protocol; this is exact formal-input correspondence.

## Full scale/service model

Distinguish global participants `N`, global retained objects `M`, ancestral
theorem-proof bytes `H`, selected unique semantic descriptor bytes `B`, selected
dependency edges `E`, cache-missing bytes `B_m`, emitted capsule bytes `L`, and
the request's genuinely demanded checking/conversion work `W`.

For one successful selected closure, charge each byte-event once:

1. Route discovery: bounded probes per demanded missing root or dependency,
   plus returned provider metadata and all failures. Under maintained healthy
   XOR coverage with bounded probes per occupied scale, discovery is
   `O(U log N)` for `U` missing IDs, plus response work. The implementation's
   finite event/deadline budget yields an incomplete result if this does not fit.
2. Transfer: at least `B_m` missing bytes, protocol overhead, retries and the
   sender's reads. No favorable CPU conversion is inferred from byte savings.
3. Resolution: `O(B+|E|)` canonical validation/hash/edge traversal under bounded
   parser shapes; cache hits avoid network transfer, not necessarily a fresh
   hash read. Count demanded descriptor reads, not all `M` objects.
4. Lowering/checking: all graph/substitution states and `L,W` are charged.
   Constants/universe specializations can make this exceed `B`; finite bounds
   and refusal are mandatory. No general `W=O(B)` assertion is made.
5. Optional certification: complete admitted setup, prepared segments,
   lifts/joins/resolutions/final verification and failures. The current tiny
   pure-Prop n10 evidence cannot be attributed to foundation replay and does
   not establish that named storage reduces its proving cost.
6. Custody/availability: exact local retained bytes, leases, renewals, repairs
   and outgoing service. A hash is not a storage promise. No finite system can
   retain an unbounded growing corpus without additional funded storage or
   selective custody/expiry.

This gives selected costs independent of `M` and theorem-proof ancestry `H`,
except through routing/load/availability and demanded semantic bodies. It does
not claim that every mathematical dependency is cheaply available or that a
finite node can answer every query. Total storage/service still grows with
the funded retained corpus.

### Sufficient, implementable operating conditions

Use finite lease epochs and owner-controlled local admission; no global ledger
or research task list is needed. For each participant `j`:

- Reserve storage for currently committed objects and new unique bytes before
  committing custody. Never evict an object while promising it for that epoch.
- Admit at most the explicitly reserved number/bytes of new descriptors and
  requests; use one operation-wide budget so branching cannot multiply limits.
- Provision finite actual CPU, I/O and connection service for renewals and
  selected admitted work. Aggregate spare network CPU does not pay an overloaded
  mandatory host or hot routing key.
- For arrival envelope `A_j(t)-A_j(s) <= sigma_j+rho_j(t-s)` measured in an
  explicitly selected resource-work unit and service curve
  `S_j(t)>=R_j max(0,t-T_j)`, choose `rho_j<R_j`. With FIFO/work-conserving
  service and bounded indivisible-job additions, backlog is at most
  `sigma_j+rho_j*T_j` and delay at most `T_j+sigma_j/R_j`; include one maximum
  nonpreemptive job where needed. Reserve buffers and deadlines accordingly.
  These are deterministic network-calculus conditions, not measurements of the
  present deployment. Enforcing caps bounds damage; it does not prove service.
- Complete renewal before remote expiry. With half-life trigger, scanner
  delay `J`, `a` due renewals, `c` workers and per-renewal service bound `d`,
  require `T_remote_min - T_local/2 > J + ceil(a/c)*d + delivery_margin`.
- Replicate demanded hot descriptors at independently reachable custodians;
  requester caps and failover bound degradation. Do not claim a provider cap
  balances load by itself or that a signature root yields complete discovery.

These conditions produce a concrete nonempty region: finite module sizes and
branching, bounded selected demand, stable reachable providers, funded storage,
and provisioned service strictly exceeding admitted work. The module feature
expands this region by removing repeated *stored/transferred* copies of shared
semantic subgraphs, when such duplication is present; repeated final checking
or proof cost is not thereby removed.

## Specific meaningful cost discriminator

For a bounded layered family where each named delta adds constant-size structure
and refers to one prior module twice at the same universe instantiation, store
one descriptor per level. The persistent named DAG requires `Theta(n)` logical
rows/edges (plus ID/index encodings); retaining all independently flattened
capsules can require `Theta(n^2)` aggregate row occurrences. One flattened
terminal capsule was already `Theta(n)` through DAG interning. This comparison
must hold exact output semantics fixed and count any separately retained lowered
cache. A cache retaining all flattened intermediates can erase the saving.

Useful qualification today: producer contributes `D0`, independent consumer
acquires it and contributes `D1`, another acquires the missing delta/shared
ancestor once and contributes `D2`; repeat acquisition has zero network payload
for already retained immutable IDs. Genuinely check each new selected final
result, reject swapped IDs/dependencies and an ill-typed new law/body. Retain
actual byte/row accounting and charges; do not run an exponential baseline or
call naming/packing alone useful mathematical growth.
