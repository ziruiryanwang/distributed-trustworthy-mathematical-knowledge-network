## Next central requirement: checked library extension without global replay

An independent contributor must be able to add a reusable mathematical type or
definition beyond the fixed F43/66-name foundation, and another contributor must
be able to use it through an explicitly checked module interface. This is more
central than more transport controls or a new popularity score: today's F-closed
lane still cannot represent ordinary growing Lean libraries as such.

Select one small, genuine contributed data-type/operation/law module, then require
this complete capability:

1. A new module's local type/definition/declaration dependencies and exact policy
   are content-bound; no sender can inject a new unproved axiom into acceptance.
2. A receiver obtains only the selected interface, an actual checked/certified
   extension boundary and any transparent bodies its demanded computation needs.
   It does not replay every proof or download every unrelated module.
3. A third participant adds a distinct result over that acquired interface using
   the ordinary public API; wrong typing and a substituted dependency both fail.
4. Search indexes the contributed type/module and advertised capabilities from
   acquired bytes, with bounded local queries and honest incompleteness.

Do not merely increase the current name limit, call a fixed trusted library dump
decentralized extension, or claim a certificate eliminates bodies needed for
conversion. First decide the explicit opacity/reduction rules and extension
checker relation; then implement the smallest supported module class. Preserve
proof-boundary independence from popularity, identities and human intentions.

## Growth evidence to attach to that requirement

Use the fixed causal policy/endowment account already adopted, not free
existential answer selection. Publish the exact shared module, distinct downstream
interfaces, real retained/certified boundaries and complete producer/consumer
costs. Give the conditional break-even reuse count from those costs and a charged
fallback when the module is unavailable. Theoretical locality/amortization
arguments should lead; one finite integration test checks that the software
really meets their assumptions.

This can establish a reusable infrastructure advantage under stated conditions.
It does not prove general mathematical interest or inevitable research discovery.
Do not add a mandatory network task list, global goal hierarchy or human-intention
field to manufacture that evidence.

## Defer until that core capability exists

Political attribution, global popularity consensus, a universal ledger,
automatic abstraction/lambda-lifting heuristics and additional cosmetic release
cuts. Wider deployment, language coverage and certificate-production economics
remain explicit limits rather than silently solved by the direct-definition demo.
