## Minimal safe definition object and conservative-extension rule

First slice: a definition D with ordered universe parameters, closed type T,
closed body v, safe status and reducibility hint; every used constant in T/v
must belong to the adopted fixed support F. Reject unsafe/partial, arbitrary
axioms, self-reference, new recursive declaration machinery and new inductive
groups. Recursor applications from F are ordinary expressions, not a new
recursion trust boundary.

Certificate statement: under the pinned F/checker relation, T has a Sort and
v has type T; kind/safety/hint/name/parameters and exact expression data equal
the committed object. A new theorem type may refer to exactly supplied D objects
whose certificates have been authenticated, plus F; selected theorem parents
remain Prop interfaces with complete recursive assumption discharge.

Use a domain-separated content ID for the fixed-profile/type/body/universe/
hint/safety tuple and explicit dependency commitments. Derive the Lean name
from that ID; do not hash a name containing its own yet-uncomputed digest.
In this first slice dependencies are F only. Later definitions referencing
contributed definitions require a separately qualified well-founded dependency
manifest; no unbounded closure claim follows from the initial slice.

Changing a definition body or reduction hint changes mathematical identity even
if an observer believes the bodies extensionally equal. A theorem interface's
identity must commit to its used definition IDs (transitively when the later
dependency extension exists). Name-only type hashes must not authenticate a
theorem under a different body. Binder/universe order and named expression
roundtrip follow the existing exact serialization policy.

Conservative-extension argument: for fresh nonrecursive d with F |- v:T,
replace each occurrence of d by its exact universe-instantiated v. The resulting
translation eliminates d, preserves typing, and converts its definitional
reduction rule to beta/delta computation in F. Therefore it adds vocabulary
without assuming a new proposition or strengthening the old language's theory.
The argument is relative to actual kernel/checker correspondence and admitted F;
it is not a consistency proof or permission to trust an unverified body.

Imported definition bodies are **semantic data**. A succinct certificate can
replace re-proving their typing history, not the computation needed to unfold
them. Readers download selected/demanded definitions, check exact commitments,
materialize them under the selected policy and pay actual reduction work. No
ancestral theorem proof packets are required. Caching an exact already admitted
definition is legitimate; making a new trust domain skip verification is not.

## Exact affordable workload candidate after that slice

Two contributed definitions over F, conceptually:

```lean
universe u
def V4Math.iter {alpha : Sort u} (f : alpha -> alpha)
    (n : Nat) (x : alpha) : alpha :=
  Nat.rec x (fun _ y => f y) n
def V4Math.plus (m n : Nat) : Nat :=
  Nat.rec n (fun _ r => Nat.succ r) m
```

These are source templates, not compiled or selected production sources. Each
uses only F constants, so does not require List, arithmetic automation or
new inductive checking. After exact definition capture, prospectively seed
`iter_intertwine` and `iter_plus`, then hold out the joint endpoint:

```lean
universe u v w
theorem V4Probe.iterated_factor_map
    {alpha : Sort u} {beta : Sort v} {gamma : Sort w}
    (f : alpha -> alpha) (g : beta -> beta) (t : gamma -> gamma)
    (h : alpha -> beta) (k : beta -> gamma)
    (hf : forall x, h (f x) = g (h x))
    (kg : forall y, k (g y) = t (k y))
    (m n : Nat) (x : alpha) :
    k (h (V4Math.iter f (V4Math.plus m n) x)) =
      V4Math.iter t m (V4Math.iter t n (k (h x)))
```

This concerns arbitrary iterated state transformations and composable factor
maps; n/m are symbolic, not huge deliberately padded constants. Exact reuse
can eliminate fresh induction in a proof by combining the two available laws.
A fair local author can instead prove the necessary induction directly, use
proof-local helper terms, or discover a shorter proof; no forced expansion or
prohibition of tactics is allowed. Native term/packet sizes should stay finite
and small, but an advantage is only a falsifiable hypothesis. The direct proof
may again be cheaper. This is a candidate scientific instrument, not an unsolved
task the product requires participants to pursue.

Both arms receive the same exact definitions and F. A gets no theorem seed;
B gets exact verified laws; C gets the same available laws but only public
non-oracle search, with irrelevant well-typed offers mixed prospectively. Neither
B nor C is compelled to use them. All receive identical model/settings/tools,
source-attempt/author budgets and final interface/contribution requirement.
No parent bodies/proof sketches or exact seed IDs are supplied to C. Broad
equality keys alone may fail retrieval; that is an honest search outcome.

Cheap gates first: definition exact-capture/conservative-extension refusals;
