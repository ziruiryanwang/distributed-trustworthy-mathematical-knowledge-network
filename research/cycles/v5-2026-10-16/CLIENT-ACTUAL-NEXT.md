## Concrete new mathematics, without a larger library dependency

Seed source opens the exact base namespace, then proves the following in a
fresh local namespace. This is a source blueprint, not a compiled artifact:

```lean
theorem fusion {A : Type u} {B : Type v} {C : Type w}
    (leafB : A -> B) (nodeB : B -> B -> B)
    (leafC : A -> C) (nodeC : C -> C -> C) (h : B -> C)
    (hleaf : forall x, h (leafB x) = leafC x)
    (hnode : forall x y, h (nodeB x y) = nodeC (h x) (h y))
    (e : Tree A) : h (fold leafB nodeB e) = fold leafC nodeC e := by
  induction e using Tree.rec with
  | leaf x => exact hleaf x
  | node l r ihl ihr =>
    exact Eq.trans (hnode (fold leafB nodeB l) (fold leafB nodeB r))
      (binary_congr nodeC ihl ihr)
```

Use `set_option autoImplicit false`, `noncomputable section`, and explicit
universe declarations as in the retained ordinary-source workload. The
consumer proves, using the acquired fusion theorem at its discovered exact
module name:

```lean
theorem project_summary {A : Type u} {B : Type v} {C : Type w}
    (leafB : A -> B) (nodeB : B -> B -> B)
    (leafC : A -> C) (nodeC : C -> C -> C) (e : Tree A) :
    (fold (fun x => (leafB x, leafC x))
      (fun x y => (nodeB x.1 y.1, nodeC x.2 y.2)) e).1 =
    fold leafB nodeB e :=
  receivedFusion (fun x => (leafB x, leafC x))
    (fun x y => (nodeB x.1 y.1, nodeC x.2 y.2))
    leafB nodeB (fun pair : B × C => pair.1)
    (fun _ => rfl) (fun _ _ => rfl) e
```

Here `receivedFusion` stands for the actual relocated imported constant, not an
axiom or a copied proof. Foundation rows contain Eq/Eq.trans/Prod and named
`Prod.fst`/`Prod.snd`, independently confirmed by the mathematics reviewer.
They do not contain `congrArg`; do not casually introduce it as an unselected
extra dependency. Lambda projection is a valid source spelling choice, not a
workaround for a missing named projection.
Require actual exported proof references to the new fusion module and actual
type references to base Tree/fold; text occurrence alone is insufficient.

Consumer semantics come only from its acquired packet via `semantic_material`.
Select the exact base and fusion journals in `describe(warrant).members`; no
old base bundle or seed authority object is passed into that consumer phase.
The packet contains native delta proof ancestry above the certified I frontier;
