# Creative growth: connect independently invented vocabularies

2026-10-24. Source/theory decision by `growth_mechanism_decision`. No runtime,
build, network request, package/state change or Git operation. This is a
recommendation for root selection, not a new feature or completed-v5 claim.

## Decision

**Keep exact discovery for reuse, but do not make exact-symbol connectivity the
only discovery route for creative investigation.** Permit a separately bounded,
advisory cross-vocabulary route using ordinary formal-pattern search first.
Its job is to expose possibly analogous work, not declare equivalence or invent
a bridge automatically. Do not build a new matcher, index or agent service now.

This changes a specific growth claim: finding an already published connection
from a known symbol is not sufficient evidence that the system helps investigators
find connections between independently invented theories. The latter is a
plausible high-value network mechanism that the completed A/B episode did not
exercise. Existing Git, Lean and search tools receive full credit for providing it
where they already do; our contribution can be making that route interoperable.

The immediate decision-changing work is a source-level interface discriminator,
specified below, not another open-ended theory episode or certificate campaign.

## What is genuinely new in this assessment

Prior notes already justify bounded capability, method/bridge reuse, selected
evidence, full-cost comparisons, lifetime locality and ordinary authoring. The
concept episode already shows independent definition formation and extension.
No additional composition, rent-or-buy or positive-net-cost inequality is needed.

The unresolved causal link considered here is **exposure to a useful unfamiliar
representation**. An agent can develop a concept by recognizing common structure
in separately developed mathematics. Such recognition need not begin with a
desired final theorem, a shared vocabulary or an already written bridge. The
network can reduce an information-access obstacle; subsequent recognition,
abstraction, model construction and proof remain real local research.

The resulting contribution might be a common abstraction with two instances, a
representation bridge, a sharper hypothesis, or a counterexample separating
apparently similar theories. A renamed duplicate alone is not a demonstrated
conceptual advance. Validity, content, leverage and novelty remain separate.

## Source fact: the existing exact index has a vocabulary boundary

The selected adapter source is
`software/v5/ordinary_formal_query/discovery/ordinary_export_adapter.py`.
`validate_spec` and `describe` expose declaration kind, exact declared-type key,
explicit type-symbol IDs, binder-domain heads and result head. Constant and
projection heads retain their exact portable SymbolIDs. The exact type key also
preserves those IDs. Nonconstant head tags are broad syntactic categories.

The inspected source has no symbol-renaming-invariant law-pattern feature.
Its source alone establishes this fact; no execution is needed. The retained A/B
query used A's `Repair` identity, already present in B's connection signatures.
It therefore crossed a **written mathematical bridge**, not this missing
cross-vocabulary boundary. Inspection and authoring offers help after a hit;
they cannot recover a candidate excluded before that hit.

### A precise obstruction

Let S be an investigator's known nonfoundation symbol identities. Consider a
conjunctive query requiring a `type-symbol(s)` feature with s in S. A declaration
whose explicit type contains no symbol in S cannot satisfy that query. This
follows directly from exact feature equality and conjunction; it does not depend
on indexing speed, proof soundness or how many replicas serve the declaration.

Two theories may encode the same laws under distinct global symbols. For example,
one law can mention `A.Repair` and `A.act`, another `B.Normalizer` and `B.run`,
each asserting idempotent action. Their exact IDs differ even when a uniform
renaming relates the law syntax. The example is an analytic witness, not a
new compiled theory or a claimed useful research workload. Bound local variables
alone are not this example: existing exact keys already ignore binder labels.

Queries using only common equality/kind/head features can find either declaration,
but may have a huge candidate set. If M records are indistinguishable by all
selected features and only b < M are inspected, some relevant record can be
omitted. Under a uniformly hidden single relevant position, exposure probability
is at most b/M. This is a counting argument about access, not a distributional
model of real research or proof that the omitted record would be useful.

Adding bridge theorems eventually reconnects vocabularies, but requiring that
bridge beforehand begs precisely the creative step we want to support.

## A useful conditional argument, not a promise of invention

Consider a finite expression profile that keeps binder/dependency structure,
universe data and chosen fixed foundation symbols, but canonicalizes the other
global symbols by their first structural occurrence. Repeated occurrences retain
the same placeholder. Apply it to explicit **laws or constructor-field types**,
not merely a concept's uninformative `Type -> Type` declaration signature.
Call the resulting canonical syntactic sketch phi(t).

For a bijective renaming rho of the nonfixed symbols, fixing the foundation and
preserving their occurrence/level structure:

    phi(rho(t)) = phi(t).

Proof: structural traversal encounters corresponding expression constructors,
binders and levels. A symbol's first occurrence allocates the same next placeholder
in both traversals; every repeated occurrence reuses it. Induction over the
traversal gives identical output. A DAG implementation must avoid exponential
tree expansion and use a documented canonical traversal; this is a mathematical
specification, not an inspected implementation or complexity result for ours.

Consequently, a correctly built sketch index *cannot exclude* a structurally
renamed counterpart merely because its vocabulary is unfamiliar. Suppose a
selected finite provider corpus has N laws, the query's sketch bucket has k
records, and all k are returned/inspected within the original budget. That
counterpart is exposed if it is in the corpus. With an ordinary balanced-key
posting index, lookup uses O(log N + k) index work after preprocessing; query
and preview parsing costs, storage and index construction remain additional.

For m selected providers with such coverage and bounds, inspecting their buckets
does not require examining all unrelated worldwide records. This is conditional
locality, not a solution to provider selection, hot sketches or absent coverage.
If k is huge, the argument gives no useful bound. Under the same uniformly hidden
position model, inspecting b records within a k-element bucket gives at most
min(1,b/k) exposure, not automatic scientific success. The improvement can be
strict because vocabulary is removed while substantial law structure is retained.

This establishes an implementable *information-access* mechanism with a concrete
failure mode and a conditional selectivity bound. It does not establish that
analogous syntax implies equivalent semantics, affordable adaptation, or faster
research. Those are deliberately not assumed by the sketch equality.

## Why this may help concepts, and where it will not

A recipient can inspect an unfamiliar law pattern, learn the second vocabulary,
and attempt a checked common abstraction or a separating countermodel. If a
bridge is found, its exact theorem can then enter the existing known-symbol
index, helping later investigators without repeating the original analogy search.
This is a plausible positive feedback channel: advisory exploration produces
checked connections which improve later exact discovery. Its strength depends
on actual investigator success and demand; no reproduction-rate or exponential
growth claim follows. Exploration need not be compulsory for any participant.

Important counterexamples and costs:

- Unrelated operations can satisfy syntactically identical laws. No semantic
  identification or proof premise may follow from a sketch match.
- A valuable analogy can reorder hypotheses, require normalization, change
  representation or need several laws jointly. The narrow sketch can miss it.
- Very generic laws create hot buckets; a bounded first page is not relevance.
- Publishing only terminal theorem types can hide the relevant laws. Conversely,
  publishing every declaration creates costs and noise; selective ordinary
  publication remains legitimate, and coverage remains explicit.
- Generalization and code adoption can cost more than rediscovery. The ordinary
  approved-project and independent checking boundaries still apply.
- A shared ranker can create homogeneous exploration. Different providers and
  local policies should remain replaceable; a global importance score is unneeded.

## Strong ordinary-tool comparator

`PREEXPORT-TOOLS.md` already inspects Loogle and existing configurable clients.
Formal patterns and wildcards are a plausible cheaper candidate route; the saved
inspection does not establish that the particular cross-vocabulary query above
is supported over our chosen packages. Its corpus, execution and resource limits
remain real. Do not infer that a new local sketch engine is necessary from the
absence of that feature in our exact index.

Give Git-plus-Lean users the same available corpora, formal search, hints, models,
proof tools and adapters. If that stack supplies the same exposure and handoff at
lower cost, use it and withdraw an incremental acceleration claim. The network's
value may then be reliable exchange and distributed access, not a new discovery
algorithm. No argument here gives our protocol an intrinsic intelligence advantage.

## Cheapest discriminator and resulting choices

After closing the at-hand offer seam, select **one source-only mapping**, not a
fresh theory or runtime campaign: identify an already retained mathematically
meaningful pair of independently named interfaces with a recognizable law
connection, or conclude none is presently available. Form the proposed pattern
from only the first interface. Inspect whether existing maintained formal search
can express it and whether a selected provider can actually cover the other.
Do not manufacture a renamed fixture and report it as useful-growth evidence.

The outcomes directly select engineering:

1. Existing search expresses the pattern and a usable corpus exists: use that
   ordinary advisory route in the investigator workflow; no new matcher/index.
2. A meaningful covered pair exists but the current syntax cannot express the
   relation: consider only a bounded nonauthoritative pattern/sketch successor,
   with an explicit collision/selectivity model before implementation.
3. The missing item is content, a provider, compatibility or researcher demand:
   do not write a matcher as its substitute. Continue the usable ordinary-project
   handoff and deployment work, stating that creative acceleration is unmeasured.

No useful retained pair has been established by this note. Thus the result is
an architectural correction and a cheap falsifiable next decision, **not** an
automatic source-edit selection. It avoids polishing exact-index plumbing as if
that alone solved open-ended concept discovery, while retaining all useful work.
