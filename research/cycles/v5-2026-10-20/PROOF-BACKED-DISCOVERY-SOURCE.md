## Exact existing public route

1. Open the selected validated Workspace under an explicitly adopted, live
   RuntimeProfile; reserve one finite grant with authoring enabled. Withdrawn
   integration-test trust is not reusable authority. Never restore saved handles.
2. Build formal specs from the local problem/signature. `CommonsClient.find`
   handles location routes; `direct_contacts.bind` handles explicitly
   chosen providers without a location run. Both use adapter.compile_query.
3. `search_offer/search_page` return bounded candidates under a committed snapshot;
   `resolve` recomputes the exact descriptor/features and returns its typed locator.
4. `packet_offers/acquire` obtain selected evidence, check it with real owners and
   issue a live warrant bound to the candidate's exact module/summary. A feature
   key, historical successful run, native stdout or stored packet is not authority.
5. `semantic_material/import_context` supports a complete retained packet. For
   selective/deferred semantics use existing SemanticReadPlan stage/select_member/
   resolve/fetch_body/preview/finish. Finish actually admits before creating context.
6. While the SAME client/context is live, `author` returns untrusted child material;
   `workspace.packets.put -> client.admit_local -> describe` checks its actual result.
   There is no need for a new admit_packet API or saved-warrant deserialization.
7. `publish` retains packet/openings/bodies and indexes chosen child exports with
   the workspace's selected adapter; incomplete publication remains reconcilable.
   Publication is structural custody, not another assertion of mathematical truth.

Convenience already exists: `remote_reader.read(client, query)` returns its live
candidate/warrant/context without closing the caller-owned client. `run/main`
closes by design. Continue in the same operation, not through two closed wrappers.
Local source/application choice belongs to the agent, not a new network planner.
