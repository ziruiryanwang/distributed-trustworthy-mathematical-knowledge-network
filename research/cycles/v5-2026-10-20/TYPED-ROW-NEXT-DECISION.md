# Typed proof rows: finite acceptance/refinement phase

2026-10-20. Source-only proposal by `core_growth`, requested by root. Canonical
root: `E:\Distributed Trustworthy Mathematical Knowledge Network`.

## Selection recommendation

**Select a constructor/field acceptance table and source refinement argument;
do not select implementation, a guest/native build, profiling, proving or a new
direct-I software lane.** This is one bounded decision phase, not a new optimizer
queue. Root owns adoption and any later consequential work.

**Root-selected refinement direction:** a conservative typed fast path for
recognized ordinary row shapes, with one whole-frame fallback to the unchanged
old relation before semantic work. Keep the old fixed-foundation representation.
The final section below chooses this hybrid over a full-domain typed rewrite;
the original accepted mathematical/logical domain is preserved by composition,
not by teaching the new decoder every exotic Serde form. No implementation is
selected by this update.

Ordinary client construction and semantic continuation are now integrated.
The next central source question is whether sharing typed export rows between
correspondence and native application removes generic row maps/redecoding while
preserving the actual old acceptance boundary. This addresses producer work
directly and is feasible to investigate on this PC without a runtime campaign.

The current memo aggregate already has a complete 113-segment execution capsule.
Its failed-prefix predecessors do not establish whole-execution fractions or a
speedup. This phase must not claim that a rewrite is necessary merely to execute,
that source row count predicts cycles, or that a smaller allocation predicts a
smaller successful proof price.

## Concrete outcome required

One auditable table must enumerate the complete current row domain and its
projection to native row values, followed by a proof/disproof of the narrow
representation refinement. A valid conclusion may be **do not implement**.

The initial 27-tag constructor census and two concrete hazards are in
[GROWTH-NEXT-DECISION](GROWTH-NEXT-DECISION.md#follow-up-activate-the-typed-row-acceptance-audit-not-a-rewrite-yet).
That census is the starting point, not a finished acceptance proof.

For each constructor, including nested inductive/recursor records, record:

- allowed exact outer tags and index domains; required versus optional fields;
- object and positional payload forms actually accepted by the full relation;
- numeric widths on the actual guest target, string/enum/Boolean/array domains;
- duplicate, extra and missing-field behavior at each old layer;
- immediate checks versus checks deferred until correspondence reaches a row;
- native application and finalization checks, including unused rows;
- correspondence-only fields lost by the native decoder, and their retained view;
- exact virtual old JSON node/depth and logical-walk accounting obligations.

The table must include the 413-row exact foundation prefix and metadata, not
only new theorem syntax. Current input and parent records also accept positional
record forms through `input.rs::ordered`; a new top-level decoder cannot silently
discard those while claiming unchanged wire acceptance.

## Untouched old domain versus a possible restricted profile

Let `Old(b)` be the **actual selected pipeline** on immutable input bytes b:
strict duplicate-rejecting integer-only JSON, aggregate census, exact foundation
comparison, current memoized correspondence, owned-row decode, native ordered
application/finalization, conditional module checking, commitments and aggregate
graph/binding rules. Successful output includes exact J and exact pending
premises, not a success Boolean.

The preferred requirement is equal successful acceptance and outputs on this
entire old domain under the same logical resource envelopes. It is **not** the
native Serde enum's domain alone, nor just the syntax currently emitted by our
fixtures. Reordered diagnostic messages or earlier rejection of an input that
eventually fails need not be identical, but no failing input may become accepted
and no previously supported success may silently become a refusal. Preserve
the old memo walk's stated logical work/depth and first-failure behavior where
that claim is specifically retained.

A narrower profile is a different option. Root could deliberately select a
strict emitted-row subset, with an injective projection into the old domain and
explicitly disclosed extra refusals. Its soundness obligation is one-way
refinement; it does not establish old-domain compatibility. **No restricted
profile is selected here.** If equality is disproportionately costly, report
the exact troublesome accepted form and the restriction's affected workflows
before recommending that choice. No authority or semantic-policy flag supplied
by a peer may enable a convenient wider interpretation.

## Known nontrivial preservation obligations

1. `OwnedExportRow` alone is lossy: native `Defn/Thm/Opaque` omit `all`, but
   correspondence requires it and checks exact singleton `[name]`. Keep a shared
   correspondence field/sidecar. `IndInfo.is_reflexive` must also survive even
   though native declaration application does not use that field.
2. All expression/level rows are indexed, but only reached rows receive some
   strict correspondence payload checks. Native application still consumes
   every row. Preserve native-accepted unused forms or label a restriction;
   do not add universal `deny_unknown_fields` based only on reached syntax.
3. Preserve ordered uparams, owner-qualified name interpretation, universe and
   expression backreferences, binder styles and `nondep` behavior. Native widths
   include `u32` indices, `u16` bvars/counts/regular hints and target `usize`
   projection indices; a new generic `u64` is not an equivalent native field.
4. `natVal`/`strVal` are forbidden by the adopted native config; `mdata` refuses
   in native application. Unreachable occurrences do not become admissible.
   Fresh axioms/quotient primitives do not gain authority by row typing.
5. Exact foundation comparison includes all original values, metadata and
   otherwise ignored fields. Choose either a proved typed/static comparison or
   preserve the old fixed prefix representation. The latter lowers scope but
   does not remove its generic representation cost. No hash-only substitute.
6. Original aggregate census counts virtual old Values, not typed records.
   Count ignored fields too; preserve duplicate-key/UTF-8/EOF/negative and
   noninteger-number refusal. Raw byte bounds do not replace node/depth bounds.
7. After correspondence, feed the exact same native row meaning to existing
   `parse_owned_rows`/`apply_row`/finalization and unchanged kernel. Do not
   serialize every typed row back to Value merely to reach the old API.
8. All group/body commitments, imported conditional premises, checked local
   declaration counts, graph/rank/closure rules and actual recursive
   `env::verify` obligations remain unchanged. Typed rows are syntax data,
   never accepted mathematics or a receipt.

## Refinement deliverable and stop rule

For a proposed private representation t and its mathematical projection R(t),
the source argument must establish:

1. **Decoder projection:** the strict old parse of accepted bytes equals R(t),
   including facts later ignored by native application. The projection is a
   specification function, not mandatory production reconstruction.
2. **Correspondence simulation:** every old lookup observes the same value,
   produced canonical types/bodies and memo summaries match, and logical work/
   depth accounting is preserved for reached and unused rows.
3. **Native simulation:** consumption yields exactly the native record the old
   decoder would yield and the same ordered construction/finalization result.
4. **Composition:** unchanged semantic checks and commitments yield the same
   exact journals/premise lists and aggregate result; recursive trust is not
   weakened or replaced by the source argument.

A private typed row plus correspondence-only fields and shape information is a
plausible extraction. A bounded exceptional legacy-row fallback is another
possible equality-preserving design, but only if ordinary supported rows avoid
generic row construction and redecoding. Decide from the table; do not implement
both alternatives. A complete typed kernel, binary wire, foundation elision,
cache protocol and new proof rule are out of scope.

Stop and recommend against the change if the design must reconstruct all generic
row Values, cannot state the accepted-domain boundary precisely, or expands into
kernel/commitment semantics. A restricted profile requires a separate root
decision, not silent narrowing to obtain a pass. If a narrow design survives,
report a concrete file/interface scope and minimum differential controls; do
not launch those controls or a build under this source-only selection.

The benefit argument at this stage is specific removed work: generic row map/key
construction and later per-row Value-to-native conversion. Typed decode/views,
sidecars, strict census and remaining native DAG construction are added/retained
costs. Their net execution/proof saving is not yet known. The phase earns its
place by resolving feasibility and assurance scope before paying those costs.

## Selected hybrid: exact common-shape fast path, unchanged old fallback

### Why this is the smallest justified option

| Option | Source/assurance obligation | Decision |
|---|---|---|
| Full-domain typed replacement | Reproduce every accepted unused-row/positional/extra-field Serde behavior, or preserve enough unknown shape data for later interpretation | Do not pursue now; the exotic-form work need not improve ordinary producer inputs |
| Strict common-shape decoder with outright rejection elsewhere | Simple fast representation but silently narrows old success unless explicitly adopted as a new restricted profile | Not selected; unchanged old compatibility is preferable |
| Common-shape typed path plus one immutable whole-frame old fallback | Prove equality on the recognized subset and use the old implementation everywhere else | **Selected source-refinement candidate** |

This is a representation dispatch, not two mathematical trust policies. Both
paths invoke the same kernel rules and must produce the same exact J/premises.
The fallback must remain the actual old source path, not a second newly retyped
approximation. No selector flag, sender assertion or saved success record grants
authority or disables the final relation/certificate checks.

### One immutable witness frame, one committed census

An aggregate contains separately framed module witnesses. Make the decision
at that existing **complete module-witness frame** boundary, not independently
for each declaration and not by mixing partially checked rows with old rows.
The aggregate wire, receipt/frontier checks and exact graph algorithm remain
unchanged. Each frame is charged once to the shared aggregate logical census.

The decoder has three explicit outcomes:

- `Typed(t, counts)`: every non-foundation row and enclosing record is in the
  conservative supported representation; strict syntax and virtual old census
  were established during consumption.
- `UnsupportedRepresentation`: a raw field/tag/payload form is outside that
  subset; discard tentative typed state and call the unchanged old parse/census/
  relation path once on the original immutable frame.
- `Malformed`: only an error whose old rejection is established independently
  of mathematical checking, such as duplicate keys, invalid JSON/UTF-8, forbidden
  numeric syntax or bound failure. Refuse; do not retry a different checker.

An unsupported case may instead safely use the old path even when the old path
will ultimately reject it. No obligation exists to predict all old failures in
the preselector. The important rule is that **correspondence, native application,
kernel, commitment, parent binding or graph failure never triggers fallback**.
The structural choice has already been made before those checks begin.

Tentative counts are private. Commit their aggregate contribution only after a
typed decode succeeds. On unsupported representation, throw them away; the old
decoder supplies the one actual virtual census. Do not mutate the global census
for a failed typed prefix and then charge the full old frame a second time, or
reset shared budgets when switching. An implementation may reject a genuinely
exceeded identical raw/logical bound before committing counts because no final
authority can result, but should preserve the existing finite-operation report
semantics rather than invent consumed-proof credit from partial syntax work.

This does not mandate two complete parses on supported input. The structural
recognizer **is the direct typed decoder**, with shared strict scalar/container
machinery and virtual counts; it must not first construct the full generic Value
tree to decide whether to avoid constructing it. On fallback, at most one typed
prefix plus one old complete parse occurs. The old fallback can be selected
immediately at the first unsupported shape, before reading the remaining frame.
The original immutable bounded bytes remain available for that one replay.

### Conservative supported representation

Initially retain the first 413 foundation rows as strict old `Value`s and call
the unchanged exact `foundation_static::matches_rows` comparison. This is not
foundation-prefix elision and removes none of its old representation cost.
Keep all non-row semantic specifications/openings/body expressions in their
unchanged Value representation too.

For suffix rows use the following finite structural subset:

- Lowercase `in/il/ie` outer index keys, exactly one matching row constructor;
  name/level/expression/declaration row outer counts stay exact. Wrong raw
  shapes may fall back rather than asking the fast path to interpret aliases.
- The exact object payload fields for the eight canonical expression tags
  `bvar/sort/const/app/lam/forallE/letE/proj`, two names and four level tags.
  Scalar and fixed-pair forms for their actual scalar/pair constructors remain
  unchanged. Object order is arbitrary; keys remain unique. Preserve widths,
  strings and enums exactly; no coercion or normalization.
- The exact emitted field sets for `def/thm/opaque`, imported declarations and
  complete inductive records/rules. Preserve ordinary `all`, `isReflexive` and
  every correspondence metadata field even where native application drops it.
- Exact object-form top-level module and parent records. Their old positional
  forms may fall back on the whole frame; no new positional decoder is needed.
- Unsupported native expression kinds, inner extra fields, positional payloads
  and unknown constructor representations select old fallback, unless an exact
  old-refusal proof justifies `Malformed`. They are not silently discarded.

The structural selector must not require proof validity. In particular, retain
arbitrary well-typed Boolean `nondep` and explicit `all` contents in typed rows;
the unchanged correspondence conditions decide where `nondep=false` and
`all=[name]` are required. A malformed mathematical reference that has a valid
unsigned syntactic field enters the typed path and is rejected by the same
semantic/reference check, not reclassified as an unsupported format to retry.

This narrows only which forms are **optimized**, not which old forms are supported.
An attacker can force the slower old path by selecting a supported old but
unoptimized representation. That is acceptable only under the original finite
request/CPU/deadline bounds; there is no promised fast path for every hostile
input and no free fallback allowance.

### Sufficient hybrid refinement theorem

Let P be the old strict parse and C the old frame census; let O be the old
conditional relation on parsed input, including its logical bounds. Let D be
the deterministic structural decoder above and N the typed semantic path.
R is the specification projection of t to the old Value interpretation.
Prove:

1. If `D(b)=Typed(t,c)`, then `P(b)=R(t)` and `C(P(b))=c`.
2. For every typed-selected b, `N(t)` succeeds **if and only if** `O(P(b))`
   succeeds, with identical exact J and pending-premise sequence and logical
   resource checks. Successful-fast-to-old implication alone is insufficient:
   it establishes soundness but could silently reject old-valid selected inputs.
3. `D(b)=Malformed` implies the old pipeline rejects under its existing raw/
   logical rules. `UnsupportedRepresentation` imposes no acceptance assertion;
   the old pipeline decides it.
4. Decoder choice has no authority side effect, and each selected path commits
   exactly one census contribution to the same aggregate state before unchanged
   mathematical graph processing. Aggregate overflow/refusal never restores an
   earlier budget or tries another path.

Then the hybrid's mathematical/logical success domain and exact outputs equal
the old pipeline's: split on the three D outcomes. On typed input use (1)-(2);
on unsupported input the old implementation is literally invoked; on malformed
input use (3). Unchanged aggregate graph rules lift frame-output equality to
the same aggregate header/premises. The final guest still verifies every exact
pending receipt claim. This is a compositional proof obligation, not a completed
source-verification theorem for code that has not been written.

### Physical costs and failure behavior are not magically equal

The equality above concerns raw/logical bounds and successful mathematical
outcomes when the selected computation completes. Same OS CPU/wall caps do not
imply equal operational completion: an unsupported frame can pay typed-prefix
work plus the full old path and exhaust a budget that the old path alone might
have met. Report that as resource-incomplete, never as a successful comparison
or a counterexample to mathematical soundness. Conversely a shorter typed path
may fit where the old one timed out. Neither direction is yet measured.

All actual preselection, discarded-prefix, fallback, allocation and cleanup
work consumes the original outer operation budget and monotone deadline.
There is no new Job/attempt/grant per branch, no automatic retry, and no receipt
production selected by a decoder result. Global mathematical census retains
its old meaning; physical repeated work is charged by actual enclosing execution,
not by falsely doubling semantic row counts.

For fallback, the deterministic upper work shape is one bounded structural
prefix plus one original frame execution; this is not a numerical time or memory
bound. The raw 16 MiB frame bound and original strict parser nesting/node limits
remain, as do the native/guest execution limits. Source comparisons may count
removed generic suffix maps/conversions but must account for the typed decoder,
sidecars and unsupported-prefix overhead.

### Next finite artifact, and no parallel alternative

Complete the exact-field/type table **only for this selected fast subset**, then
prove its projection/correspondence/native-record simulation. List all other raw
forms as deterministic whole-frame old fallback. This avoids an exhaustive
new implementation of exotic Serde acceptance while preserving it through the
old path. Keep old foundation Values initially. Do not develop the full-domain
typed rewrite or a direct-I code path in parallel.

If the subset can reach existing `parse_owned_rows` without generic suffix-row
reconstruction and the four hybrid obligations hold, root can decide on one
implementation seam and its smallest differential controls. If not, stop this
candidate before a build. A future proof job still requires a separately justified
successful-production route and cost decision; this representation result does
not itself price or fund one.
