## Selected checks

   no error field; complete unforced closure; numeric/type/resource/log checks.
   Cumulative process count is not confused with concurrent active count.
2. Actual ordinary output files: permitted zero-length stdout, exact log lengths,
   streaming byte/entry bounds, active-check propagation and nonmutation.
3. Real terminal facade methods and structural bindings with explicit inert
   issuer/authority doubles: refusal preserves existing handles, contexts and
   selections; positive cache reuse; exact J/A membership failures remain fatal;
   unsupported mixed dispatch calls no issuer (mixed dispatch itself is doubled).
4. Actual public trial wrappers with explicit state/acquisition doubles: local,
   offered/exact dispatch; strict API refusal; final guard failures. Both new
   wrappers must refuse authority withdrawal, original grant deadline, original
   owner deadline and controller-CPU exhaustion caused by the final census.

   and trust doubles, using the real report/output helper. CleanNone preserves

   and expiry during final refusal evidence I/O revoke. Old strict contract stays.
6. Corresponding A owner transitions, including changed header, member revocation
   and retained output reservations.
