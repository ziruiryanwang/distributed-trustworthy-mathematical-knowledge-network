# Growth target: ordinary sharing is part of v5, not its opponent

2026-10-20, core_growth. Source/theory only; no execution or changed release gate.

## Decision that changes the work

**Do not require every v5 mechanism to beat ordinary decentralized sharing O.
O is itself an allowed implementation of our commons.** Distinguish isolated
cache-aware local development L, ordinary native sharing O, and optionally
certified sharing V. A positive L-to-O result supplies a commons benefit even
if V-to-O has a negative premium. The separate large-ancestry requirement still
needs certified reuse; native sharing does not replace it.

The [earlier comparator](PROOF-SEARCH-REUSE-COMPARATOR.md) already permits a
named executable policy rather than an ideal mathematical optimizer. Its SAT
NO-GO remains correct. The mistake to avoid now is treating lack of a profitable
new certificate as lack of any potentially beneficial commons mechanism.
No new solver, proof job, economics module or scheduler is warranted here.

## Concrete supported case: avoid repeated cold source preparation

Use the already checked `EvaluatorUniqueness.lean`, not an invented hard theorem.
It states that two arbitrary Tree evaluators satisfying the same four constructor
equations agree. Its native witness has697rows/50,017bytes; the **complete mixed
packet is498,641bytes**, including its genuine BASE receipt. Source:
[actual outcome](EVALUATOR-METHOD-OUTCOME.md). Module:
`bbf0845d2622374699a93a9d8ccc6e565dd1c985e72441ec0eeae41bb03fc0c5`.
No new M certificate is needed for this bounded native delta.

Define policy B: an owner-managed Lean source library builds a missing method
through `import_context -> author -> admit_local`, retains its accepted output,
and uses the cached method thereafter. Both arms have the same source recipe,
BASE, compiler/exporter/checker, optimization flags and persistent cache policy.
Do not force rebuilding warm methods. In O, a cold library may instead discover
and acquire the producer's canonical packet through existing
`search_offer/search_page/resolve -> SemanticReader -> finish`, then use the
same theorem on its own evaluator equations. Publication uses existing
`publish`/semantic custody. This is **validated build reuse**, not proof-search
hardness or new mathematical discovery. An accepted prebuilt cache is a warm hit
in both arms and earns no saving.

This route is source-supported and has an actually accepted producer artifact;
M's discovery/publication/recipient path was not run. Do not call it qualified.
Its11-binder, two-universe type contains only foundation/known-BASE references,
not an unknown M symbol. A caller can construct the formal contract's type
before learning M's identifier. The adapter's existing `declared-type-key` is

    hash_value("discovery-declared-type", {universes: 2, type: relocated_type}).

Relocation introduces no M reference because the type has no M-local reference.
Exact syntax/universe conventions must agree. Search remains conditional on an
available selected index containing that key with a bounded eligible posting
range; no arbitrary-equivalence solver or global scan follows. This removes the
private-vocabulary obstruction of the rejected SAT case.

## Constructive cost region

Take n genuinely cold library histories within supported horizon H, each building
or importing M once and including its later cached uses. The first producer runs
B in both routes; its ordinary creation cost occurs in both and cancels. If that
creation is network-only speculative work, charge the entire cost to F instead.
Use an explicit additive resource model with stated CPU/bytes/byte-time prices
or compare coordinates separately; memory and deadlines constrain feasibility.

- E lower-bounds the *actual source-preparation path eliminated* per cold library:
  supervised Lean elaboration/export and associated conversion.
- A upper-bounds every other incremental successful-sharing cost: formal query,
  discovery, complete-packet transfer, rejected candidates, extra semantic/context
  work, validation differences and attributed provider work. Cancel only actually
  identical common operations.
- F and M(H) bound incremental publication, establishment, finite custody,
  replication/repair, retirement and unsuccessful production. Q bounds failed
  searches/cleanup and their changed fallback cost, without renewed grants.

Then the n histories avoid n executions of the concrete preparation path, and

    cost(L) - cost(O) >= n*(E-A) - F - M(H) - Q.

Unlike an unspecified proof-search margin, **E names an existing avoidable path
and supported accepted artifact**. Source reasoning establishes the call elision;
retained event traces can price it. Full receiving cost is not50,017witness bytes
or a0.03125-second native subset. The retained author worker's1.609375Job CPU
seconds is one diagnostic measurement, not a universal E lower bound or whole
preparation cost. Shared startup/checking cancels only for identical actual work.

The region E>A and

    floor((F+M(H)+Q)/(E-A))+1 <= n_max(H)

is a positive full-cost native-sharing region. n_max must satisfy the existing
finite retention and per-queue [capacity conditions](GROWTH-OPERATING-REGION.md).
No empirical demand or current positive physical-CPU margin is asserted. A
local policy directly constructing a cheaper canonical proof changes E and may
erase the region; disclose that alternative instead of calling B optimal.

## Consequence and limits

Keep **native-first sharing of short reusable methods** as a first-class route;
do not gate its publication or use on another certificate. Existing
I-plus-native-delta operation supports this. Finish exact-custody integration,
which preserves reader/discovery work while finding needed semantics. Do not
build another all-native authoring lane or rerun M merely for this argument.

The source-known example gives only a narrow **same-formal-endpoint capability
cost benefit**, conditional on the region above. It is not the stronger useful
mathematical-growth result. If recipients instead initially lack M's source and
the method itself, avoided local discovery/construction may add value, but its
cost needs a separately specified real local policy; it cannot be borrowed from
source-build timing. Saved work permits more warranted capability only when a
supported next target fits the saved allowance; it does not guarantee novelty.

The existing evidence does not price A/F/M or establish E>A. For this particular
policy claim, a full-pipeline cost bound is the missing economic input, not a
hard-theorem construction or successful new certificate. Measure it only if
decision-changing and unchanged retained evidence cannot bound it. No new generic
dossier, calculator or experiment is selected by this note.

This separates conditional build reuse, observed profitable use, avoided discovery
and the optional certification premium. Substantive independent applications,
later contributed successors and generally advancing succinct frontiers remain
separate full-v5 obligations; none is relabeled satisfied here.
