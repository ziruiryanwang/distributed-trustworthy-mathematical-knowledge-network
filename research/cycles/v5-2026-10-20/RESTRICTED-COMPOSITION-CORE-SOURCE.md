## Consequential boundary

The five files under `software/v5/restricted_composition` implement the narrowed
CORE-PLAN: original I semantic image and unchanged J/policy commitments; exact
parent openings; singleton theorem-only signatures; scoped canonical terms;
theorem checking; and bounded conditional conclusions. No original checker,
native row parser, complete foundation array, inferred trust flag or receipt
verification is executed by this path. The existing original crate supplies
only canonical/hash/commitment/policy/journal helpers and the conclusion type.

`relation::check_with_census(Value)` returns the original conditional conclusion
and derived source census. `check` discards the census; `check_bytes` adds the
raw 256-KiB cap and existing strict duplicate-key parser. The aggregate must
establish every exact returned parent J. No result here is portable authority.

Foundation installation uses the same inspectable tiny projection that the
native harness will compare with the retained F. Eq is native type6, parameter
name2, binder names4/9/9. Eq.trans is type103, parameter name11, binder names
4/5/28/29/30/31. Both have one universe. Eq.trans's successive Eq applications
have de Bruijn arguments `(3,2,1)`, `(4,2,1)`, `(5,4,2)`. The fixed full-F
digest and 413-row/23,313-byte bounds remain unchanged.

Interning compares complete structures, including binder origin/style and exact
qualified addresses. Conversion permits exact node identity or an explicit
root Pi/Pi or Lambda/Lambda branch; there is no application congruence or
reduction fallback. Fresh locals never reuse IDs. Opening, closing and universe
substitution have per-operation context-aware caches and monotone frame-wide
work charges. Universe replacement is simultaneous. Internal imax nodes are
never simplified. Zero-ending imax chains are recognized only at the explicit
root-Sort comparison branch and theorem-Prop test. Inference may conservatively
refuse other correct mathematics; see the IMAX-ADDENDUM refinement correction.

## Source-review corrections and conservative bounds

- Adaptive review correctly observed that plain syntax-directed application
  would also accept a direct lambda redex without reducing it. The selected
  normal public profile is narrower: parsing now rejects an application whose
  parsed function is a Lambda. Recursive parsing catches nested spines too.
  This applies equally to imported types, new types and proofs.
- Generated traversal recursion has an additional depth128 refusal cap. Public
  expression depth48, JSON depth64, open binders64 and work200,000 are unchanged.
- The final theorem comparison uses inferred-type versus declared-type, matching
  the original `check_declar` orientation without an extra symmetry argument.
- Root's further source review adopted raw imax preservation. The native
  constructor does not simplify, so eager reduction could invalidate a blanket
  pointer-identity argument under nested nodes. Only native's explicit root-sort
  quick branch and Prop recognition now use the zero-chain equivalence.
- The 8,192 source-expression and 65,536 source-level visits count occurrences
  before interning. The tiny compiled F projection is excluded from those
  source counters but included in internal work/address/node accounting.
- Conservative virtual-W rows/bytes/nodes/correspondence bounds are checked
  without constructing W. Extra theorem/closure/address/name restrictions
  only refuse cases; they never relax the retained original relation.
