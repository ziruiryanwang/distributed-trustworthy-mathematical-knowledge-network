# Retained-advertisement focused controls

2026-10-21, core_growth. Source-only under RETAINED-ADVERTISEMENT-SELECTION.
No product import/execution, runtime/build, external network, deletion or Git
mutation. Root selects any later one-time bounded run after independent review.

Sources: `software/v5/retained_advertisement/controls.py` and this directory's
`Select-RetainedAdvertisementControls01.ps1`. They stage the installed114 map
plus four already qualified replacements and seven placement/network additions:
121 logical SDK files, 127 physical source files including runner/harness, and
19 input/runtime pins. The two fresh product successors replace the old service
and advertisement. No predecessor test suite is imported or repeated.

The nine new methods cover:

| Boundary | Required observation |
|---|---|
| Two-run SEALED_SERVING restart | Fresh grant/locator paths; same retained receipt/custody/index; one current-run route dispatch after original publisher/service windows; old-token new-write refusal. |
| OPEN, unknown, partial, wrong-domain and oversized representative | One local call charged; no route reservation, dispatch, data rewrite or automatic repair. |
| Missing posting/snapshot/name/packet offer/body | Refusal without fetching proof/body data or repairing local state. |
| Original retention horizon | Reject active end beyond horizon and already expired horizon; expiry immediately after reservation COMMIT prevents publish; expiry after publish prevents confirmed observation; uncertain slot stays spent. |
| Dispatch/observation failure | Durable one-opportunity reservation; same-run repeat returns uncertainty with no new publish. |
| Original run/config caps | max_runs=1 cannot restart or be enlarged; endpoint-mismatched reopen fails and retains its consumed core-run charge. |
| Owner cancellation | One tracked inner task; concurrent restore refuses; cancellation clears busy state but does not refund route opportunity. |
| Close during actual restoration | Cancel/drain owner task before SQLite closure; unfinished dispatch remains uncertain. |
| Close before advertisement busy-entry | Track the task independently of the busy bit; cancel it before closing stores. |

Real Workspace/controller/ledger/packet/module/index/route SQLite behavior is
used. Listener and Node lifecycle/commands are deliberately simulated; actual
sockets, child processes and all receipt/native admission entry points are
forbidden. Each fixture includes one definition and requested transparent body
plus an explicitly inert terminal-I packet. It is never mathematically admitted.

During restoration the harness additionally forbids packet get/inspect/write,
body get/write, group write, index admit and legacy controller acquisition helpers.
The bounded selected group opening remains permitted. Tiny fixture table-dump
hashes and SQL total_changes check no data/receipt changes; these are test-only
comparisons, not proposed whole-library scans in the product.

The selector only creates a fresh selection JSON; it does not run tests. Its
prospective single allocation is 60 CPU seconds / 120 wall seconds / 384 MiB /
two processes with 1 MiB output limits. This is not a proof-production,
network-throughput, RAM or filesystem-saturation experiment. Original failed
or successful evidence is neither rewritten nor rerun.

Passing these controls would qualify only changed retained-route guards and
task lifecycle under simulation. Actual cross-run network discovery, hostile
OS isolation, physical lifecycle reclamation, global recall and net useful
growth remain distinct claims. Source hashes and the independent review must
be adopted before any launch; no PASS is asserted here.
