## Proposed bounded boundary

Preserve the whole formal type tree, binder and universe structure, fixed
foundation names, and repeated occurrences of the same nonfoundation constant.
Forget only nonfoundation symbol addresses by deterministic first-occurrence
numbering. This seeks types modulo injective nominal renaming, not logical or
definitional equivalence. Clients still acquire exact descriptors and verify
mathematics through existing gates; no fingerprint can confer authority.

The simpler existing alternative is current edge/head/symbol conjunction search.
Proceed only if a concrete same-edge-set collision is separated without knowing
the target ModuleID, with bounded extraction and unchanged default namespaces.
If existing APIs already express the constraint, do not add another mechanism.
