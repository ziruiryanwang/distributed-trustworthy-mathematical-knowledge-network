## Exact new mathematical artifact

Write T for the actual BASE.Tree, with its authenticated leaf/node/recursor;
write U for the **discovered and freshly checked** M theorem. These names denote
exact imported identities, not replacements with similarly named local types.
Both initial routes know the same foundation and BASE vocabulary. The recipient
does not initially possess U, its proof/source, its ModuleID or its theorem name.

Define a new local operation by the actual recursor:

```text
mirror : T A -> T A
mirror(leaf a)   = leaf a
mirror(node l r) = node (mirror r) (mirror l)
```

Its source should define `mirror` directly with Tree.rec and the motive
`fun _ => T A`, leaf branch `fun a => leaf a`, and node branch
`fun _ _ ml mr => node mr ml`. This avoids a new recursive termination proof,
pattern-match auxiliary inventory or extra fold/map dependency. It is an
ordinary transparent definition; its committed body is real reusable semantics.

Apply U at codomain B=T A with leaf/node as the common algebra, and

```text
h(t) = mirror(mirror(t))
k(t) = t.
```

All four required equations are definitional reductions of this recursor:

```text
h(leaf a)   = leaf a
h(node l r) = node (h(l)) (h(r))
k(leaf a)   = leaf a
k(node l r) = node (k(l)) (k(r)).
```

For the only interesting reduction, the first mirror swaps l/r; the second
swaps them back, yielding `node (mirror(mirror l)) (mirror(mirror r))`.
Thus four reflexivity proofs and one application of U establish

```text
forall (A : Type u) (t : T A), mirror(mirror(t)) = t.
```

No induction is repeated in this local theorem; U supplies it. No excluded
middle, choice, function extensionality, arithmetic foundation, arbitrary
semantic equivalence decision or fresh succinct proof is required. The node
case is not the leaf case in disguise: mirror genuinely reverses arbitrarily
deep ordered binary trees. Examples are not a substitute for this universal law.

The new module should export both the operation and the law. The mirror body is
not hidden behind a theorem wrapper, and publication alone is not acceptance.
Future agents may use either the operator or its law. The network does not
decide that the operation is globally novel or economically important.

## A later contribution that actually uses the new law

A later local agent with the mirror interface can investigate whether it is
injective. After discovering and freshly checking the involution law V, prove

```text
forall x y : T A, mirror(x) = mirror(y) -> x = y.
```

For p:mirror(x)=mirror(y), equality elimination derives
q:mirror(mirror(x))=mirror(mirror(y)). Then the explicit proof is

```text
Eq.trans (Eq.symm (V x)) (Eq.trans q (V y)).
```

Use the existing foundation's Eq.ndrec for q; do not silently import congrArg,
which is not in the 22-declaration foundation. Concretely its motive is
`fun z => mirror(mirror(x)) = mirror(z)` and its initial proof is reflexivity.
This proof consumes V twice and does not reconstruct mirror involution or Tree
induction. A recipient can later apply injectivity to a formal local equality.
Its mathematical value is the reusable implication, not the count of two calls.

The exact ordinary dependency shapes are BASE(I)->M(native)->V(native) and then
V->injectivity(native), with selected shared BASE semantics. First V acceptance
has at most M plus V native nodes above BASE; injectivity has at most M, V and its
new node. This bound is independent of unrelated global theorems. It is not a
bound for indefinitely long arbitrary native chains or large parameters, and
does not replace the separate scalable certified-frontier work.
