The purpose is to identify a specific product obstruction or an already adequate
ordinary route before investing in a new search mechanism. It is not an efficacy
experiment, a full-cost comparison, or a release gate that replaces final v5.

Select one fresh, no-conversation-inheritance investigator. Its initial source
corpus is exactly the five whole modules pinned in CORPUS.json: existing repair,
closure, finite-plan, contextual-refinement and recipient developments. These
sources are available as ordinary library material. They are not hidden targets
or automatically new discoveries. Published index endpoints are a subset of
the library and have separately retained public receipts.

The brief is: investigate when independently specified finite-state updates can
be combined or substituted while preserving a useful observable property. Choose
the claim; definitions, general laws and exact refutations are all eligible.
Record consulted material and decisions. Ordinary source tools are fully
permitted; the current mathematical index is optional. Do not require index use
to make the software appear valuable.

First phase is source-only, at most20 deliberate source/document read actions,
512KiB aggregate content, and one proposed extension or one concrete operability
obstruction. Workspace guard/instructions are necessary setup outside that
research-read count. No native check, API purchase, owner operation, service,
package mutation or theorem replay is selected. A query request records the
vocabulary known beforehand and its intended information need; root may later
select a bounded public call. Stop the first phase when that decision is ready.

Only INVESTIGATION.md and optional Proposed.lean under this directory are
assigned to the investigator. Root owns actual calls and Git. A later check can
reuse approved compiled libraries; it must not repeat cold grounding or the
completed reciprocal campaign. There is no automatic retry or lease renewal.

Access limits are investigator instructions, not an enforced sandbox. The
subagent has a shared filesystem and unrestricted tools. Model compute is not
reliably metered here. Report these limits and any assistance; do not infer
autonomy, blinded comparison, population benefit or causal speedup. A cheap
ordinary-source success or an unused index is a legitimate diagnostic outcome.
