### Concrete accounting counterexample

Suppose actual starting stock is 80 units under a 100-unit cap. A historical release of 20 units is already reflected in that starting measurement. A new plan adds 30. The unqualified formula could compute `80 + 30 - 20 = 90` and admit the plan, although actual stock would reach 110. Only releases from after that exact base cut can reduce the projection. Replanning from actual stock must not preserve an old subtraction term merely because its history remains recorded.

The work inequality has a related but usually conservative ambiguity: adding already spent work to the original unreduced reservation can double-count the same operation and falsely reject progress. It should use spent work plus genuinely remaining reservations/aftercare. A lost outcome still retains its conservative unresolved allocation; fixing double-counting is not permission to reclaim uncertainty.

### Concrete progress counterexample

An owner can create a new completed run between frames, forcing more collisions for the old pool's remaining inputs. If each frame replans only a bounded amount but this happens indefinitely, “bounded replanning” per frame provides no uniform bound on total additional work. Likewise, unrelated eligibility changes can make cleanup newly payable without completing an old-pool obligation. A decreasing measure for one fixed plan does not prove drainage across those changing plans.

The proposed policy already provides important protection: fallback partial-step frames accept no new public cohort; a surviving handoff/cursor must be resolved before a different step; the original old pool cannot be renamed or expanded. The repair should make the remaining liveness premises explicit, not discard those protections or claim that every permitted arrival stream is serviced.
